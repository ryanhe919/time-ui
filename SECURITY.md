# Security Policy

## Supported Versions

| Version  | Supported          |
| -------- | ------------------ |
| latest   | ✅                 |
| < latest | ❌ (upgrade first) |

## Reporting a Vulnerability

**Do not open a public issue.** Instead:

1. Email **ryanhe0919@gmail.com** with:
   - A description of the vulnerability
   - Steps to reproduce
   - Affected package(s) and version(s)
2. You will receive an acknowledgement within **48 hours**.
3. A fix will be developed privately. Once ready:
   - A patch release is published.
   - A [GitHub Security Advisory (GHSA)](https://docs.github.com/en/code-security/security-advisories) is created.
   - The affected version range is deprecated via `npm deprecate`.

We follow coordinated disclosure — please allow us time to patch before publishing details.
