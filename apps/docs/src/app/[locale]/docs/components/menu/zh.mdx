# 菜单 Menu

可键盘导航的下拉菜单：基于 Popover anchor，支持声明式（`<Menu.Item>` / `<Menu.Section>` / `<Menu.Divider>`）与数据驱动（`items`）两种写法、单选 / 多选 / 无选择三种 selectionMode、roving focus + 输入字符跳转、shortcut / icon / description / danger / href 等修饰符。

<Callout variant="info" title="Menu 还是 Popover？">
  - **Menu**：一组互斥的命令（操作、跳转、勾选）。键盘 `↑↓` 漫游，回车触发，符合 ARIA `menu` 模式。
  - **Popover**：富内容的小卡片（表单、链接组、说明文字），无 menu 行为。
</Callout>

## 基础用法

`onAction(key)` 在任意 item 触发时回调，配合 `<Menu.Section>` 做语义分组、`<Menu.Divider>` 插入分隔线、`isDanger` 标记危险操作。

  trigger={<Button variant="bordered">Open menu</Button>}

## 多选 selectionMode

`selectionMode="multiple"` 时点击 item 切换勾选，菜单不会自动关闭；右侧渲染勾选 indicator。`selectedKeys` / `defaultSelectedKeys` 双轨控制。

  onSelectionChange={setSelected}

## 数据驱动

把 items / sections 作为扁平数组传给 `items` prop，避免在大型菜单里手写 JSX。两种写法可以互换，但同一菜单不要混用。

```tsx
<Menu
  trigger={<Button>Sort</Button>}
  selectionMode="single"
  defaultSelectedKeys={['name-asc']}
  items={[
    {
      type: 'section',
      sectionKey: 'name',
      label: 'Name',
      items: [
        { itemKey: 'name-asc', label: 'A → Z' },
        { itemKey: 'name-desc', label: 'Z → A' },
      ],
    },
    {
      type: 'section',
      sectionKey: 'date',
      label: 'Date',
      items: [
        { itemKey: 'date-newest', label: 'Newest first' },
        { itemKey: 'date-oldest', label: 'Oldest first' },
      ],
    },
  ]}
/>
```

## 修饰符

每个 `MenuItem` 都可以加：

- `icon` — 左侧 16×16 图标。
- `shortcut` — 右侧次级文字（通常是 `⌘K` 这类快捷键提示）。
- `description` — label 下方一行次级描述。
- `isDanger` — 文字与 hover bg 走 danger 色板。
- `href` — 渲染为 `<a>` 而非 `<button>`，回车与点击都会导航。
- `isDisabled` — 键盘跳过、点击不触发。

### MenuSection / MenuDivider

`MenuSection` 接受可选 `label` 渲染分组标题；`MenuDivider` 渲染 1px 水平线，仅作视觉分隔，不参与 keyboard navigation。

<Callout variant="info" title="可访问性">
  trigger 与 menu 通过 `aria-haspopup="menu"` + `aria-expanded` + `aria-controls` 关联。打开后菜单 `role="menu"`（multiple 走 `menu` + `menuitemcheckbox`），方向键漫游、Home / End 跳首尾、字符键键入做前缀匹配，Esc 关闭并把焦点归还到 trigger。
</Callout>
