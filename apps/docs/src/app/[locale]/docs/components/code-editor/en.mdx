# Code Editor

A syntax-highlighted code editor built on [CodeMirror 6](https://codemirror.net/), with toolbar, language switching, and an extension point for AI-powered coding suggestions. Shipped behind the `@timeui/react/code-editor` subpath export so CodeMirror dependencies **never land in the main bundle** unless you import the editor.

## Installation

The `CodeEditor` is a separate sub-entry to keep heavy CodeMirror dependencies out of the main bundle. Install peer dependencies first:

```bash
npm install @timeui/react codemirror @codemirror/view @codemirror/state @codemirror/commands @codemirror/language @codemirror/autocomplete @codemirror/lang-javascript @codemirror/lang-python @codemirror/lang-css @codemirror/lang-html @codemirror/lang-json
```

Then import from the sub-entry:

```tsx
import { CodeEditor } from '@timeui/react/code-editor';
```

## Basic Usage

Controlled string state. Every keystroke fires `onChange(value)`.

<CodeEditorBasicDemo />

```tsx
import { useState } from 'react';
import { CodeEditor } from '@timeui/react/code-editor';

export function Demo() {
  const [code, setCode] = useState('const x = 42;');
  return (
    <CodeEditor
      value={code}
      onChange={setCode}
      language="typescript"
      aria-label="Code editor"
    />
  );
}
```

## Languages

Supports JavaScript, TypeScript, Python, CSS, HTML, and JSON. Switch the active language via the `language` prop or the toolbar language selector (`toolbar={{ showLanguageSelect: true }}`).

## States

`isDisabled` blocks all interaction; `isReadOnly` keeps focus and selection but rejects edits; `isInvalid` surfaces the danger color via the shared field-style helper.

## Toolbar Configuration

Pass a `ToolbarConfig` object to show only specific toolbar items:

```tsx
<CodeEditor
  toolbar={{
    showCopy: true,
    showLineWrap: true,
    showLanguageSelect: true,
    showLineNumbers: false,
    showFullscreen: false,
  }}
/>
```

Pass `toolbar={false}` to hide the toolbar entirely.

## AI Suggestions

Pass an `onAISuggest` callback to enable the AI suggest button in the toolbar. When triggered, it calls your function with the current code and cursor position, then inserts the first suggestion at the cursor.

```tsx
<CodeEditor
  value={code}
  onChange={setCode}
  onAISuggest={async (code, position) => {
    const res = await myAIService.complete(code, position);
    return [{ text: res.suggestion, label: 'AI suggestion' }];
  }}
/>
```

## Custom Extensions

Pass additional CodeMirror 6 extensions via the `extensions` prop. They are appended after the built-in set.

```tsx
import { EditorView } from '@codemirror/view';

<CodeEditor
  extensions={[
    EditorView.theme({ '&': { fontSize: '16px' } }),
  ]}
/>
```

### `ToolbarConfig` fields

| Field | Type | Default | Description |
|-------|------|---------|-------------|
| `showCopy` | `boolean` | `true` | Copy code button |
| `showLineWrap` | `boolean` | `true` | Toggle line wrap button |
| `showLineNumbers` | `boolean` | `true` | Toggle line numbers button |
| `showLanguageSelect` | `boolean` | `true` | Language selector dropdown |
| `showFullscreen` | `boolean` | `true` | Fullscreen toggle button |

### `AISuggestion` shape

```ts
interface AISuggestion {
  text: string;     // code string to insert
  label?: string;   // display label shown in the suggestion UI
}
```

<Callout variant="info" title="Bundle impact">
  CodeMirror is **not** bundled with `@timeui/react`. Install the CodeMirror peer packages and import only from the dedicated subpath — `import { CodeEditor } from '@timeui/react/code-editor'` — so pages that never render the editor remain unaffected.
</Callout>

<Callout variant="info" title="Accessibility">
  The wrapper has `role="group"` and forwards `aria-label` / `aria-labelledby` / `aria-describedby`. CodeMirror's editable layer (`.cm-content`) carries `role="textbox"` and `contenteditable="true"` natively. Disabled / read-only state is mirrored to CodeMirror via `EditorState.readOnly` and `EditorView.editable`. All default keyboard shortcuts remain active, including full keyboard navigation. Provide `aria-label` (or wrap in a labelled `FormField`) when there is no visible label.
</Callout>
