# SegmentedControl

An iOS-style segmented selector: pick one value from a small mutually exclusive set. Internally each segment is a real `<input type="radio">`, so arrow-key navigation, screen readers, and native form submission work for free; the selected state is carried by a single highlight "thumb" that slides between segments.

## Basic usage

The canonical "time range / category filter" — pass an `options` array.

<LiveDemo
  code={`<SegmentedControl
  aria-label="Date range"
  defaultValue="1d"
  options={[
    { value: '1d', label: '1D' },
    { value: '7d', label: '7D' },
    { value: '1m', label: '1M' },
    { value: '1y', label: '1Y' },
    { value: 'all', label: 'All' },
  ]}
/>`}
>

## With icons

Each `option` accepts an `icon`; in horizontal mode it sits to the left of the label. If `label` is icon-only, supply `aria-label` so the segment still has an accessible name.

<LiveDemo
  code={`<SegmentedControl
  aria-label="Inbox"
  value={tab}
  onChange={setTab}
  options={[
    { value: 'chats', label: 'Chats', icon: <ChatIcon /> },
    { value: 'emails', label: 'Emails', icon: <MailIcon /> },
  ]}
/>`}
>
  <SegmentedControlInboxDemo />
</LiveDemo>

## Icon-only

When every `option` has only an `icon` and no visible `label`, the control auto-switches to a "square segment + circular indicator" shape — perfect for compact tool buttons like theme or view switchers. Each icon must supply `option["aria-label"]` to keep an accessible name.

<LiveDemo code={`<SegmentedControl
  size="sm"
  aria-label="Theme"
  defaultValue="light"
  options={[
    { value: 'light', label: <SunIcon />,  'aria-label': 'Light' },
    { value: 'dark',  label: <MoonIcon />, 'aria-label': 'Dark'  },
  ]}
/>

<SegmentedControl

    { value: 'columns', label: <ColumnsIcon />, 'aria-label': 'Columns' },

/>`}>

</LiveDemo>

## Controlled

`value` + `onChange` puts you in full control; `onChange` fires once per selection with the next `value`.

<LiveDemo code={`import { useState } from 'react';
import { SegmentedControl } from '@timeui/react';

type Range = '1d' | '7d' | '1m' | '1y' | 'all';

export function DateRange() {
  const [range, setRange] = useState<Range>('1d');
  return (
    <SegmentedControl<Range>
      aria-label="Date range"
      value={range}
      onChange={setRange}
      options={[
        { value: '1d', label: '1D' },
        { value: '7d', label: '7D' },
        { value: '1m', label: '1M' },
        { value: '1y', label: '1Y' },
        { value: 'all', label: 'All' },
      ]}
    />
  );
}`}>
  <SegmentedControlRangeDemo />
</LiveDemo>

## Full width

By default the control sizes to its content. `isFullWidth` stretches it across the parent container with equally-sized segments.

<LiveDemo
  code={`<SegmentedControl
  isFullWidth
  aria-label="Plan"
  defaultValue="monthly"
  options={[
    { value: 'monthly', label: 'Monthly' },
    { value: 'yearly', label: 'Yearly · save 20%' },
  ]}
/>`}
>
  <div style={{ width: 'min(420px, 100%)' }}>
    <SegmentedControl
      isFullWidth

<Callout variant="info" title="Accessibility">
  The control wraps native `<input type="radio">` in a `role="radiogroup"`, so the browser handles arrow / Home / End navigation, form submission, and screen-reader announcements ("X of Y") natively. When an `option.label` is icon-only, supply `option["aria-label"]` so each segment still has an accessible name. `prefers-reduced-motion` disables the indicator's slide transition.
</Callout>
