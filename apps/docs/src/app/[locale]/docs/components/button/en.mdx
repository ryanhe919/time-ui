# Button

Trigger actions with a clear, accessible affordance. TimeUI's `Button` ships with
seven visual variants, six semantic colors, five size steps (xs / sm / md / lg / xl),
and a controllable corner radius — composing to 42+ visual combinations that
cover everything from compact toolbars to prominent call-to-actions.

Seven visual styles. Pair each with any `color`.

## API

<Callout variant="info" title="Legacy props">
  The legacy `variant` values (`'primary' | 'secondary' | 'outline' | 'danger'`) are still
  accepted and mapped internally to the new `variant` + `color` model. Prefer the new
  API — explicit `color` + `variant` composes across all 42 visual combinations.
</Callout>

<Callout variant="info" title="Accessibility">
  Renders a native `<button>`. Keyboard focus is visible (`outline` + `outline-offset`),
  press uses `transform: scale(0.97)`, and animations respect `prefers-reduced-motion`.
  `loading` sets `aria-busy="true"` and keeps the label alongside the spinner.
</Callout>
