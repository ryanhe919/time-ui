# 按钮 Button

为操作提供清晰、可访问的入口。TimeUI 的 `Button` 提供 **七种视觉样式**、**六种语义色**、**五档尺寸**（xs / sm / md / lg / xl），以及可控的**圆角** —— 可组合出 42+ 种视觉形态，覆盖从密集控件到行动召唤的各种场景。

## 样式 Variants

七种视觉样式，可与任意 `color` 组合使用。

  <Button color="primary" variant="flat">Flat</Button>
  <Button color="primary" variant="faded">Faded</Button>
  <Button color="primary" variant="shadow">Shadow</Button>
  <Button color="primary" variant="ghost">Ghost</Button>
</Flex>`}>

## 纯图标按钮 Icon-only

设置 `isIconOnly` 后按钮变为正方形（width = height、内边距清零）。把图标作为 `children`
（或通过 `startIcon` 传入）即可。所有 `variant`/`color`/`size` 以及 `radius="full"` 的
胶囊形态都支持；务必同时传 `aria-label` 以保证无障碍。

<LiveDemo code={`<Flex gap={8} align="center">
  <Button isIconOnly color="primary" aria-label="新增"><PlusIcon /></Button>
  <Button isIconOnly variant="bordered" aria-label="搜索"><SearchIcon /></Button>
  <Button isIconOnly variant="light" aria-label="菜单"><MenuIcon /></Button>
  <Button isIconOnly variant="shadow" color="danger" aria-label="删除"><XIcon /></Button>
  <Button isIconOnly radius="full" variant="shadow" color="primary" size="lg" aria-label="悬浮新增"><PlusIcon /></Button>
</Flex>`}>
  <ButtonIconOnlyDemo />
</LiveDemo>

<Callout variant="info" title="兼容旧属性">
  旧的 `variant` 取值（`'primary' | 'secondary' | 'outline' | 'danger'`）仍被支持，内部会映射到新的 `variant` + `color` 模型。新代码请优先使用新 API —— 显式的 `color` + `variant` 可组合出全部 42 种视觉形态。
</Callout>

<Callout variant="info" title="可访问性">
  渲染为原生 `<button>` 元素。键盘焦点有明显 outline，按压使用 `transform: scale(0.97)`，所有动画都遵循 `prefers-reduced-motion`。`loading` 会设置 `aria-busy="true"`，并在 spinner 旁保留标签文本。
</Callout>
