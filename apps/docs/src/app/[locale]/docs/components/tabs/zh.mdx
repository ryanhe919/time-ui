# 标签页 Tabs

把同一上下文下的多块内容折叠成一组可切换的 panel。提供 `underline` / `pills` / `bordered` 三种 variant，水平和垂直两种方向；同时支持声明式（`<Tab>` + `<TabPanel>`）和数据驱动（`items={[...]}`）两套 API。

<Callout variant="info" title="什么时候不用 Tabs">
  Tabs 是 **navigation** 语义（`role="tablist"` + `role="tabpanel"`），用于在已有内容的多个面板之间切换。如果你只是想在表单里二选一 / 多选一，请用 [`SegmentedControl`](/zh/docs/components/segmented-control) —— 它是 `radiogroup` 语义，会被表单提交。Tabs 切换的是 **panel**，SegmentedControl 切换的是 **value**。
</Callout>

## 基础用法

声明式写法：每个 `<Tab itemKey>` 内嵌一个 `<TabPanel>` 描述这一页的内容。

<LiveDemo code={`<Tabs aria-label="Repository" defaultSelectedKey="readme">
  <Tab itemKey="readme" label="README">
    <TabPanel itemKey="readme">仓库说明文档。</TabPanel>
  </Tab>
  <Tab itemKey="issues" label="Issues">
    <TabPanel itemKey="issues">已上报的问题列表。</TabPanel>
  </Tab>
  <Tab itemKey="prs" label="Pull requests">
    <TabPanel itemKey="prs">待审阅的合并请求。</TabPanel>
  </Tab>
</Tabs>`}>
  <div style={{ width: '100%', maxWidth: 480 }}>
    <Tabs aria-label="Repository" defaultSelectedKey="readme">
      <Tab itemKey="readme" label="README">
        <TabPanel itemKey="readme">仓库说明文档。</TabPanel>
      </Tab>
      <Tab itemKey="issues" label="Issues">
        <TabPanel itemKey="issues">已上报的问题列表。</TabPanel>
      </Tab>
      <Tab itemKey="prs" label="Pull requests">
        <TabPanel itemKey="prs">待审阅的合并请求。</TabPanel>
      </Tab>
    </Tabs>
  </div>
</LiveDemo>

## 数据驱动 items

当 panel 数量较多、或来自远端时，用 `items` 更简洁。`items` 优先级高于 `children`。

<LiveDemo code={`<Tabs
  aria-label="Account settings"
  defaultSelectedKey="profile"
  items={[
    { itemKey: 'profile',  label: 'Profile',  content: <p>个人资料 panel。</p> },
    { itemKey: 'security', label: 'Security', content: <p>安全设置 panel。</p> },
    { itemKey: 'billing',  label: 'Billing',  content: <p>账单与发票 panel。</p> },
  ]}
/>`}>
  <TabsBasicDemo />
</LiveDemo>

## 视觉变体 Variants

`underline`（默认）—— 简洁的下划线 indicator；`pills`—— 胶囊式背景，灵感来自 macOS 的分段控件；`bordered` —— 带 panel 容器边框，适合内容区独立展示。

<LiveDemo code={`<Stack spacing={24}>
  <Tabs aria-label="underline" variant="underline" defaultSelectedKey="a"
    items={[{ itemKey: 'a', label: 'Overview' }, { itemKey: 'b', label: 'Activity' }, { itemKey: 'c', label: 'Settings' }]} />
  <Tabs aria-label="pills" variant="pills" defaultSelectedKey="a"
    items={[{ itemKey: 'a', label: 'Overview' }, { itemKey: 'b', label: 'Activity' }, { itemKey: 'c', label: 'Settings' }]} />
  <Tabs aria-label="bordered" variant="bordered" defaultSelectedKey="a"
    items={[{ itemKey: 'a', label: 'Overview', content: 'Overview 内容' }, { itemKey: 'b', label: 'Activity', content: 'Activity 内容' }, { itemKey: 'c', label: 'Settings', content: 'Settings 内容' }]} />
</Stack>`}>
  <Stack spacing={24}>
    <Tabs
      aria-label="underline"
      variant="underline"
      defaultSelectedKey="a"
      items={[
        { itemKey: 'a', label: 'Overview' },
        { itemKey: 'b', label: 'Activity' },
        { itemKey: 'c', label: 'Settings' },
      ]}
    />
    <Tabs

        { itemKey: 'a', label: 'Overview' },

## 垂直方向 Vertical

`orientation="vertical"` 适合"侧边导航 + 主区面板"的设置型布局。键盘导航自动切换为 `↑` / `↓`。

<LiveDemo code={`<Tabs
  aria-label="Settings nav"
  orientation="vertical"
  variant="bordered"
  defaultSelectedKey="profile"
  items={[
    { itemKey: 'profile',  label: 'Profile',       content: '个人资料 panel。' },
    { itemKey: 'team',     label: 'Team',          content: '团队成员管理 panel。' },
    { itemKey: 'security', label: 'Security',      content: '账户安全 panel。' },
    { itemKey: 'billing',  label: 'Billing',       content: '账单与发票 panel。' },
  ]}
/>`}>
  <div style={{ width: '100%', maxWidth: 520 }}>
    <Tabs
      aria-label="Settings nav"
      orientation="vertical"
      variant="bordered"
      defaultSelectedKey="profile"
      items={[
        { itemKey: 'profile', label: 'Profile', content: '个人资料 panel。' },
        { itemKey: 'team', label: 'Team', content: '团队成员管理 panel。' },

## 禁用 disabledKeys

整体禁用用 `isDisabled`；单独禁用某些 tab 用 `disabledKeys`，键盘方向键会自动跳过。

<LiveDemo code={`<Tabs
  aria-label="Plan"
  defaultSelectedKey="free"
  disabledKeys={['team']}
  items={[
    { itemKey: 'free',  label: 'Free' },
    { itemKey: 'pro',   label: 'Pro' },
    { itemKey: 'team',  label: 'Team (即将推出)' },
  ]}
/>`}>
  <Tabs
    aria-label="Plan"
    defaultSelectedKey="free"
    disabledKeys={['team']}
    items={[
      { itemKey: 'free', label: 'Free' },
      { itemKey: 'pro', label: 'Pro' },
      { itemKey: 'team', label: 'Team (即将推出)' },
    ]}
  />
</LiveDemo>

## 懒加载 isLazy

`isLazy` 时，只挂载当前激活 panel —— 切换才挂载下一个。适用于大型 dashboard 或需要按需请求数据的场景。

<LiveDemo code={`<Tabs
  aria-label="Dashboard"
  isLazy
  defaultSelectedKey="overview"
  items={[
    { itemKey: 'overview',  label: 'Overview',  content: <Overview /> },
    { itemKey: 'analytics', label: 'Analytics', content: <Analytics /> },  // 切到这一项才会挂载
    { itemKey: 'reports',   label: 'Reports',   content: <Reports /> },
  ]}
/>`}>
  <Tabs
    aria-label="Lazy demo"
    isLazy
    defaultSelectedKey="overview"
    items={[
      { itemKey: 'overview', label: 'Overview', content: 'Overview 已挂载。' },
      { itemKey: 'analytics', label: 'Analytics', content: '切到这一项才挂载。' },
      { itemKey: 'reports', label: 'Reports', content: '同上 —— 按需挂载。' },
    ]}
  />
</LiveDemo>

<Callout variant="info" title="可访问性">
  Tabs 渲染原生 `role="tablist"` + `role="tab"` + `role="tabpanel"`，并实现 roving tabindex：方向键切换（横向 `←` `→`，纵向 `↑` `↓`）、`Home` / `End` 跳首尾、自动跳过 disabled。indicator 滑动遵循 `prefers-reduced-motion`。当容器没有可见标题时，请通过 `aria-label` 或 `aria-labelledby` 给 tablist 命名。
</Callout>
