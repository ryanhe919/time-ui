# 输入框 Input

单行文本输入——最核心的表单原子。提供 **4 种 variant** × **6 种语义色** × **5 档 size**，支持 `startContent` / `endContent` 插槽、`isClearable` 清除按钮与 `password` 的显隐切换。

传入 `label` / `description` / `errorMessage` 时会隐式使用 [`FormField`](./form-field) 包装，得到统一的排版与 a11y 串联。

## 样式 Variants

四种表单专用样式——取 Button 的子集，并新增 `underlined` 适配 Material 风格表单。

## 受控用法

受控模式下 `value` + `onChange(value)` 每次键入都会触发回调（参数为**解包后的字符串**，不是 event）。下面的 demo 组合了邮箱校验、password toggle 与 clearable：

<LiveDemo code={`import { useState } from 'react';
import { Input, Stack } from '@timeui/react';

export function SignUpForm() {
  const [email, setEmail] = useState('');
  const [password, setPassword] = useState('');
  const emailInvalid = email.length > 0 && !email.includes('@');

  return (
    <Stack spacing={16}>
      <Input
        type="email"
        label="邮箱"
        value={email}
        onChange={setEmail}
        isClearable
        isRequired
        errorMessage={emailInvalid ? '请输入合法的邮箱' : undefined}
      />
      <Input
        type="password"
        label="密码"
        value={password}
        onChange={setPassword}
        isRequired
      />
    </Stack>
  );
}`}>
  <InputFormDemo />
</LiveDemo>
