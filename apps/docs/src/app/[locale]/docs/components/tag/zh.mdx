# 标签 Tag

紧凑的标记控件：标注分类、状态、属性。3 种 variant（solid / soft / outline）、6 种 color、5 档 size、可关闭、可点击、可加 start/end 内容。

<Callout variant="info" title="Tag 还是 Badge？">
  - **Tag**：用户可见、表达**内容属性**（"React"、"Bug"、"已完成"），可关闭 / 点击。
  - **Badge**：通常**附着在另一个元素上**（图标的右上角、按钮的角标），表达计数 / 状态点。
</Callout>

## Variant

`solid`（实心，强调）/ `soft`（淡背景，常用默认）/ `outline`（描边，最克制）。

## 可关闭

`isClosable` 在尾部渲染一个 `×` 按钮；点击时触发 `onClose(e)`。建议把删除逻辑放在 `onClose` 而不是 `onPress`。

<LiveDemo code={`<Tag isClosable onClose={() => console.log('closed')}>React</Tag>
<Tag isClosable color="primary" onClose={() => {}}>TypeScript</Tag>`}>
  <TagClosableDemo />
</LiveDemo>

## 可点击

设置 `isInteractive` 后整个 tag 变为可聚焦的 `<button>`，回车 / 空格触发 `onPress`，常用于"作为筛选器"。

<LiveDemo code={`<Tag isInteractive onPress={() => console.log('pressed')}>Filter: React</Tag>`}>
  <TagInteractiveDemo />
</LiveDemo>

## start / end content

```tsx
<Tag startContent={<DotIcon />} color="success">Online</Tag>
<Tag endContent={<ExternalIcon />}>Visit site</Tag>
```
