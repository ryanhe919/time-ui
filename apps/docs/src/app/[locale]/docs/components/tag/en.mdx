# Tag

A compact label control for categories, statuses, or attributes. Three variants (solid / soft / outline), six colours, three sizes, optional close button, optional press behaviour, and start / end slots.

<Callout variant="info" title="Tag vs. Badge">
  - **Tag** — a primary, user-visible label describing **content** ("React", "Bug", "Done"). Can be closed or pressed.
  - **Badge** — typically **decorates another element** (icon, button, avatar) to convey count or status.
</Callout>

## Variants

`solid` (high emphasis) / `soft` (the default subtle background) / `outline` (most restrained).

## Closable

`isClosable` renders a trailing `×` button; click fires `onClose(e)`. Put removal logic on `onClose`, not `onPress`.

<LiveDemo code={`<Tag isClosable onClose={() => console.log('closed')}>React</Tag>
<Tag isClosable color="primary" onClose={() => {}}>TypeScript</Tag>`}>
  <TagClosableDemo />
</LiveDemo>

## Interactive

With `isInteractive`, the entire tag becomes a focusable `<button>`. Enter / Space invoke `onPress` — useful for chip-style filters.

<LiveDemo code={`<Tag isInteractive onPress={() => console.log('pressed')}>Filter: React</Tag>`}>
  <TagInteractiveDemo />
</LiveDemo>

## Start / end content

```tsx
<Tag startContent={<DotIcon />} color="success">Online</Tag>
<Tag endContent={<ExternalIcon />}>Visit site</Tag>
```

<Callout variant="info" title="Accessibility">
  The default form is a `<span>`; `isInteractive` switches to a `<button>` with native keyboard behaviour. The close button is its own focusable element with `aria-label="Remove"`. Setting `isDisabled` adds `aria-disabled="true"` and suppresses events.
</Callout>
