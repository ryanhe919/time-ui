# 下拉选择 Select

**自定义 listbox**（不再是原生 `<select>`）——外观与 [`Input`](./input) 完全对齐的 4 × 6 × 5 组合，支持**搜索过滤**、**最大高度 + 滚动**、键盘与屏幕阅读器可达。

数据源有两种写法：声明式 `items` 数组（推荐），或 `<SelectOption>` children（会被父组件读取 props 而非渲染为 DOM `<option>`）。

## 长列表 + 滚动

选项很多时，popover 自动限制高度（默认 280px），多余部分出现滚动条。也可以用 `maxListHeight` 自定义。

<LiveDemo code={`<Select
  isSearchable
  label="时区"
  placeholder="选择时区…"
  maxListHeight={240}
  items={Array.from({ length: 30 }, (_, i) => ({
    value: 'tz-' + i,
    label: 'GMT' + (i - 12 >= 0 ? '+' : '') + (i - 12) + ':00',
  }))}
  fullWidth
/>`}>
  <Select
    isSearchable
    label="时区"
    placeholder="选择时区…"

  />
</LiveDemo>

父组件会读取 SelectOption 的 `value` / `disabled` / `children` 来生成自定义 listbox 的选项——运行时 SelectOption 本身不渲染 DOM。

## 受控用法

<LiveDemo code={`import { useState } from 'react';
import { Select } from '@timeui/react';

const FRAMEWORKS = [
  { value: 'react', label: 'React' },
  { value: 'vue', label: 'Vue' },
  { value: 'svelte', label: 'Svelte' },
  { value: 'solid', label: 'Solid' },
  { value: 'angular', label: 'Angular', isDisabled: true },
];

export function FrameworkPicker() {
  const [value, setValue] = useState('react');
  return (
    <Select
      label="选择你的前端框架"
      items={FRAMEWORKS}
      value={value}
      onChange={setValue}
      fullWidth
    />
  );
}`}>
  <SelectDemo />
</LiveDemo>

<Callout variant="info" title="可访问性">
  trigger 是 `role="combobox"` + `aria-haspopup="listbox"` + `aria-expanded`；popover 是 `role="listbox"`；选项是 `role="option"` 并带 `aria-selected` / `aria-disabled`。键盘支持：`↑/↓` 高亮切换，`Home/End` 跳首尾，`Enter` 选中，`Space` 选中（或在未打开时打开），`Esc` 关闭并返回焦点。`isSearchable` 打开后焦点先进搜索框；关闭时焦点回到 trigger。label / description / errorMessage 的串联由隐式 FormField 处理。
</Callout>
