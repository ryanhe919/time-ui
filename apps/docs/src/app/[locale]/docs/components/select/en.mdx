# Select

A **custom listbox** dropdown (no longer a native `<select>`), visually matched
to [`Input`](./input) (same four variants × six colors × five sizes). Supports
**search filtering**, **max-height + scroll**, and full keyboard + screen-reader
access.

Two ways to pass options: the declarative `items` array (preferred), or
`<SelectOption>` children (whose props are read at render time — they don't
emit DOM themselves).

## Searchable

`isSearchable` mounts a search box at the top of the popover and filters
options by case-insensitive substring match on the label. Ideal for long
lists or when users can't remember the full option name.

## Long list + scrolling

When there are many options the popover clamps to a max height (280px by
default) and a scrollbar appears. Customize with `maxListHeight`.

<LiveDemo code={`<Select
  isSearchable
  label="Time zone"
  placeholder="Pick a time zone…"
  maxListHeight={240}
  items={Array.from({ length: 30 }, (_, i) => ({
    value: 'tz-' + i,
    label: 'GMT' + (i - 12 >= 0 ? '+' : '') + (i - 12) + ':00',
  }))}
  isFullWidth
/>`}>
  <Select
    isSearchable
    label="Time zone"
    placeholder="Pick a time zone…"

      value: 'tz-' + i,

    }))}
    isFullWidth
  />
</LiveDemo>

build its custom listbox — at runtime `SelectOption` renders nothing itself.

## Controlled usage

<LiveDemo previewSource="children" code={`import { useState } from 'react';
import { Select } from '@timeui/react';

const FRAMEWORKS = [
  { value: 'react', label: 'React' },
  { value: 'vue', label: 'Vue' },
  { value: 'svelte', label: 'Svelte' },
  { value: 'solid', label: 'Solid' },
  { value: 'angular', label: 'Angular', isDisabled: true },
];

export function FrameworkPicker() {
  const [value, setValue] = useState('react');
  return (
    <Select
      label="Pick your framework"
      items={FRAMEWORKS}
      value={value}
      onChange={setValue}
      isFullWidth
    />
  );
}`}>
  <SelectDemo />
</LiveDemo>

<Callout variant="info" title="Accessibility">
  The trigger is `role="combobox"` + `aria-haspopup="listbox"` +
  `aria-expanded`; the popover is `role="listbox"`; options are
  `role="option"` with `aria-selected` / `aria-disabled`. Keyboard:
  `↑/↓` moves the highlight, `Home/End` jumps to the ends, `Enter` selects,
  `Space` selects (or opens when closed), `Esc` closes and returns focus.
  With `isSearchable` the search input is focused on open; focus returns to
  the trigger on close. Label / description / errorMessage wiring is handled
  by the implicit FormField.
</Callout>
