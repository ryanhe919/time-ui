# 步骤条 Steps

线性流程的进度指示：表单分步、向导、签收 / 审批流。3 种 variant（`default` 编号 / `dot` 圆点 / `navigation` 可点跳转）、横 / 纵两种方向、3 档 size、按 `current` 与 `status` 自动推断每步状态。

## 基础用法

传 `items` 数组，`current`（0-based）指出当前步骤；早于它的自动 `finish`，等于它的为 `process`，晚于它的为 `wait`。

<LiveDemo code={`<Steps
  current={1}
  items={[
    { title: 'Account',   description: 'Create your account.' },
    { title: 'Profile',   description: 'Tell us about yourself.' },
    { title: 'Workspace', description: 'Pick a name.' },
    { title: 'Done',      description: 'Start building.' },
  ]}
/>`}>
  <Steps
    current={1}
    items={[
      { title: 'Account', description: 'Create your account.' },
      { title: 'Profile', description: 'Tell us about yourself.' },
      { title: 'Workspace', description: 'Pick a name.' },
      { title: 'Done', description: 'Start building.' },
    ]}
  />
</LiveDemo>

## 状态 status

`status` 是当前 step 的整体状态：`process`（默认，进行中）/ `finish`（已完成）/ `wait`（等待）/ `error`（出错）。每个 item 也可以单独 `status` 覆盖（最高优先级）——例如把第 2 步标红表示该步骤校验失败。

<LiveDemo code={`<Steps
  current={1}
  status="error"
  items={[
    { title: 'Personal' },
    { title: 'Payment', description: 'Card declined.' },
    { title: 'Confirm' },
  ]}
/>`}>
  <Steps
    current={1}
    status="error"
    items={[
      { title: 'Personal' },
      { title: 'Payment', description: 'Card declined.' },
      { title: 'Confirm' },
    ]}
  />
</LiveDemo>

## Variant

- `default`：圆形 indicator + 序号 / 勾。
- `dot`：极简圆点，文字仍然是 step 主体。
- `navigation`：把每个 step 渲染成可聚焦按钮，配合 `isClickable` 与 `onChange` 跳转，常用于多步表单的「上一步」。

<LiveDemo code={`<Steps variant="dot" current={1} items={[
  { title: 'Connected' }, { title: 'Configuring' }, { title: 'Live' },
]} />`}>
  <Steps
    variant="dot"
    current={1}
    items={[
      { title: 'Connected' },
      { title: 'Configuring' },
      { title: 'Live' },
    ]}
  />
</LiveDemo>

## 纵向 direction="vertical"

适合内容较长 / 每步带描述的场景，比如审批流时间线。

<LiveDemo code={`<Steps
  direction="vertical"
  current={1}
  items={[
    { title: 'Submitted',  description: 'You filed the request.' },
    { title: 'Reviewing',  description: 'A reviewer is looking at it.' },
    { title: 'Approved' },
  ]}
/>`}>
  <Steps
    direction="vertical"
    current={1}
    items={[
      { title: 'Submitted', description: 'You filed the request.' },
      { title: 'Reviewing', description: 'A reviewer is looking at it.' },
      { title: 'Approved' },
    ]}
  />
</LiveDemo>

## 自定义 indicator icon

每个 item 都可以传 `icon` 覆盖默认 indicator——常用于给步骤加业务图标。

```tsx
<Steps
  current={2}
  items={[
    { title: 'Pick file', icon: <FileIcon /> },
    { title: 'Upload',    icon: <UploadIcon /> },
    { title: 'Done',      icon: <CheckIcon /> },
  ]}
/>
```
