# Steps

A linear-flow progress indicator: multi-step forms, wizards, approvals. Three variants (`default` numbered / `dot` minimal / `navigation` clickable), horizontal or vertical orientation, three sizes, and automatic per-step status inferred from `activeIndex` + `status`.

## Basic usage

Pass an `items` array; `activeIndex` (0-based) marks the active step. Anything before it is `finish`, the active step is `process`, and anything after is `wait`.

<LiveDemo code={`<Steps
  activeIndex={1}
  items={[
    { title: 'Account',   description: 'Create your account.' },
    { title: 'Profile',   description: 'Tell us about yourself.' },
    { title: 'Workspace', description: 'Pick a name.' },
    { title: 'Done',      description: 'Start building.' },
  ]}
/>`}>
  <Steps
    activeIndex={1}
    items={[
      { title: 'Account', description: 'Create your account.' },
      { title: 'Profile', description: 'Tell us about yourself.' },
      { title: 'Workspace', description: 'Pick a name.' },
      { title: 'Done', description: 'Start building.' },
    ]}
  />
</LiveDemo>

## Status

`status` describes the current step: `process` (default), `finish`, `wait`, or `error`. Each `item` can also carry its own `status` to override (highest priority) — e.g. paint step 2 red to indicate validation failure.

<LiveDemo code={`<Steps
  activeIndex={1}
  status="error"
  items={[
    { title: 'Personal' },
    { title: 'Payment', description: 'Card declined.' },
    { title: 'Confirm' },
  ]}
/>`}>
  <Steps
    activeIndex={1}
    status="error"
    items={[
      { title: 'Personal' },
      { title: 'Payment', description: 'Card declined.' },
      { title: 'Confirm' },
    ]}
  />
</LiveDemo>

## Variants

- `default` — circular indicator with numerals / a check mark.
- `dot` — minimal dot; the text remains the visual anchor.
- `navigation` — every step becomes a focusable button; pair with `isClickable` and `onActiveIndexChange` for "back" buttons in multi-step forms.

<LiveDemo code={`<Steps variant="dot" activeIndex={1} items={[
  { title: 'Connected' }, { title: 'Configuring' }, { title: 'Live' },
]} />`}>
  <Steps
    variant="dot"
    activeIndex={1}
    items={[
      { title: 'Connected' },
      { title: 'Configuring' },
      { title: 'Live' },
    ]}
  />
</LiveDemo>

## Vertical

Best when each step has a longer description, e.g. an approval timeline.

<LiveDemo code={`<Steps
  direction="vertical"
  activeIndex={1}
  items={[
    { title: 'Submitted',  description: 'You filed the request.' },
    { title: 'Reviewing',  description: 'A reviewer is looking at it.' },
    { title: 'Approved' },
  ]}
/>`}>
  <Steps
    direction="vertical"
    activeIndex={1}
    items={[
      { title: 'Submitted', description: 'You filed the request.' },
      { title: 'Reviewing', description: 'A reviewer is looking at it.' },
      { title: 'Approved' },
    ]}

</LiveDemo>

## Custom indicator icon

Each item can pass `icon` to replace the default indicator with a domain-specific glyph.

```tsx
<Steps
  activeIndex={2}
  items={[
    { title: 'Pick file', icon: <FileIcon /> },
    { title: 'Upload',    icon: <UploadIcon /> },
    { title: 'Done',      icon: <CheckIcon /> },
  ]}
/>
```

<Callout variant="info" title="Accessibility">
  The container is an `<ol aria-label="…">` with each step as an `<li>`. In `navigation` variant, steps upgrade to `<button>` and the active one is marked `aria-current="step"`. Keyboard reach is native: Tab into the buttons, Enter / Space jumps.
</Callout>
