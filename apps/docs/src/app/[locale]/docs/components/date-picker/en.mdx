# Date Picker

`DatePicker` selects a single date; `DateRangePicker` selects a contiguous range. Both share one calendar panel: full keyboard navigation (arrows + PageUp/Down + Home/End), min / max bounds, per-day disabling, configurable week start and locale, all anchored via Popover.

<Callout variant="info" title="Two components, one page">
  `DatePicker` and `DateRangePicker` share almost every prop (both extend `DatePickerCommonProps`). The only differences are the `value` shape and the extra `visibleMonths` / `presets` on `DateRangePicker`.
</Callout>

## DatePicker — single date

The everyday "pick a date" control. `isClearable` exposes a clear button when a value is set; `showTodayButton` adds a "Today" shortcut at the bottom of the panel.

<LiveDemo code={`import { useState } from 'react';
import { DatePicker } from '@timeui/react';

export function Demo() {
  const [value, setValue] = useState<Date | null>(null);
  return (
    <DatePicker
      value={value}
      onChange={setValue}
      placeholder="Pick a date"
      isClearable
      showTodayButton
    />
  );
}`}>
  <DatePickerBasicDemo />
</LiveDemo>

## DateRangePicker — range

A range picker with presets and a two-month view. The first click sets `start`; if the second click is earlier than `start` the values swap automatically. While hovering, the panel previews the upcoming range.

<LiveDemo code={`<DateRangePicker
  value={value}
  onChange={setValue}
  presets={[
    { label: 'Today', value: { start: today, end: today } },
    { label: 'Last 7 days', value: { start: addDays(today, -6), end: today } },
    { label: 'Last 30 days', value: { start: addDays(today, -29), end: today } },
  ]}
  isClearable
/>`}>
  <DateRangePickerDemo />
</LiveDemo>

## Constraints and disabling

- `minValue` / `maxValue` clamp the selectable window; out-of-range days are disabled.
- `isDateUnavailable(date)` lets you disable arbitrary days, e.g. weekends:

```tsx
<DatePicker
  isDateUnavailable={(d) => {
    const day = d.getDay();
    return day === 0 || day === 6; // Sunday / Saturday
  }}
/>
```

## Localisation and formatting

- `weekStartsOn` — `0` (default, Sun) / `1` (Mon) / …
- `locale` — BCP-47 tag forwarded to the internal `Intl.DateTimeFormat` (e.g. `'zh-CN'`).
- `format(d)` / `parse(s)` — fully override input rendering and parsing.

<Callout variant="info" title="Accessibility">
  The trigger is a combobox-pattern `<input>`; the overlay is a `dialog`. The calendar is `role="grid"` + `gridcell`: arrows move, PageUp/Down change month, Shift+PageUp/Down change year, Home / End jump to the start / end of the row, Enter selects. Under `prefers-reduced-motion` all transitions are removed.
</Callout>
