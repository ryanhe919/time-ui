# 日期选择 Date Picker

`DatePicker` 选取单个日期，`DateRangePicker` 选取一段连续区间。两者共用同一个日历面板：键盘可达（方向键 + PageUp/Down + Home/End）、可设最小 / 最大值、可禁用任意天、可自定义周首日与本地化格式，弹层基于 Popover 渲染。

<Callout variant="info" title="一篇文档两个组件">
  `DatePicker` 与 `DateRangePicker` 共享几乎所有 props（继承 `DatePickerCommonProps`），区别只在 `value` 类型与 `DateRangePicker` 额外的 `visibleMonths` / `presets`。
</Callout>

## DatePicker — 单日期

最常见的"选个日期"。`isClearable` 在已有值时显示清除按钮，`showTodayButton` 在面板底部加一个"今天"快捷按钮。

<Callout variant="info" title="快速切换年份">
  点击面板头部的月份标题，可切换到年份网格；左右箭头会按 12 年一组翻页，点中某个年份后立即返回日期视图。键盘仍支持 `Shift + PageUp / PageDown` 按年切换。
</Callout>

## DateRangePicker — 区间

带 presets 与双月视图的区间选择。第一次点击设定 `start`，第二次点击若早于 `start` 则自动交换；hover 时面板内会高亮预览区间。

<LiveDemo code={`<DateRangePicker
  value={value}
  onChange={setValue}
  presets={[
    { label: 'Today', value: { start: today, end: today } },
    { label: 'Last 7 days', value: { start: addDays(today, -6), end: today } },
    { label: 'Last 30 days', value: { start: addDays(today, -29), end: today } },
  ]}
  isClearable
/>`}>
  <DateRangePickerDemo />
</LiveDemo>

## 约束与禁用

- `minValue` / `maxValue` 限定可选区间；超出范围的天会被禁用。
- `isDateUnavailable(date)` 自定义任意天禁用，如禁选周末：

```tsx
<DatePicker
  isDateUnavailable={(d) => {
    const day = d.getDay();
    return day === 0 || day === 6; // 周日 / 周六
  }}
/>
```

## 本地化与格式

- `weekStartsOn`：`0`（默认，Sun）/ `1`（Mon）...
- `locale`：传给内部 `Intl.DateTimeFormat` 的 BCP-47 语言标记（如 `'zh-CN'`）。
- `format(d)` / `parse(s)`：完全自定义输入框的展示格式与解析逻辑。

  触发器为带 combobox 模式的 `<input>`，弹层以 `dialog` 渲染。日历支持鼠标点击标题切换年份视图；在日期网格里也可用方向键移动、PageUp/Down 切月、Shift+PageUp/Down 切年、Home / End 跳到本周首尾、回车选定。`prefers-reduced-motion` 下取消所有过渡。
</Callout>
