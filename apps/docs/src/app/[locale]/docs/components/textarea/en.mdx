# Textarea

Multi-line text input. Visually identical to [`Input`](./input) — same four variants, six semantic colors, five size steps — but with height and auto-sizing controls: fixed `rows`, `minRows`/`maxRows` auto-grow, and a built-in `showCount` character counter.

## Variants

Same four recipes as Input: `flat` / `bordered` / `faded` / `underlined`.

## Fixed rows

Without `minRows` / `maxRows`, a fixed `rows` (default `3`) is used — the height doesn't change with content.

<LiveDemo code={`<Textarea rows={5} placeholder="Fixed 5-row height" />`}>
  <Textarea rows={5} placeholder="Fixed 5-row height" />
</LiveDemo>

## Auto-size

Passing `minRows` / `maxRows` enables auto-grow — height tracks content until the upper bound, then scrolls.

<LiveDemo code={`<Textarea
  minRows={2}
  maxRows={6}
  placeholder="Starts at 2 rows; grows up to 6 before scrolling."
/>`}>
  <Textarea
    minRows={2}
    maxRows={6}
    placeholder="Starts at 2 rows; grows up to 6 before scrolling."
  />
</LiveDemo>

## Character count

`showCount` (with a `maxLength`) draws `n/max` in the bottom-right corner. It turns `warning` near the cap and `danger` over it.

<LiveDemo code={`<Textarea
  showCount
  maxLength={80}
  defaultValue="Try typing past 80 characters and watch it flip."
/>`}>
  <Textarea
    showCount
    maxLength={80}
    defaultValue="Try typing past 80 characters and watch it flip."
  />
</LiveDemo>

## Controlled usage

Controlled value + auto-size + counter in a single field:

<LiveDemo code={`import { useState } from 'react';
import { Textarea } from '@timeui/react';

export function FeedbackForm() {
  const [value, setValue] = useState('');
  return (
    <Textarea
      label="Feedback"
      description="Press Enter for a newline; 120 chars max."
      value={value}
      onChange={setValue}
      minRows={3}
      maxRows={8}
      maxLength={120}
      showCount
      fullWidth
    />
  );
}`}>
  <TextareaDemo />
</LiveDemo>

<Callout variant="info" title="Accessibility">
  `ref` points at the native `<textarea>`. `Enter` never submits the form (native behavior). Unlike Input, **Escape does not clear** — accidental loss of long text is painful, so we deliberately differ. When the counter is visible it's mirrored into a sr-only node via `aria-describedby` (for example "42 of 80 characters used"). All transitions honour `prefers-reduced-motion`.
</Callout>
