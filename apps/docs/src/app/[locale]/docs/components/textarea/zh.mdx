# 多行输入 Textarea

多行文本输入。视觉与 [`Input`](./input) 一致——共享 4 种 variant、6 种语义色、5 档 size，区别在**高度**与**自适应**：支持固定 `rows`、`minRows` / `maxRows` 自适应、`showCount` 字数统计。

## 样式 Variants

同 Input，4 种：`flat`（软底色 chip + hairline 描边）/ `bordered`（清晰中性边框）/ `faded`（底色 + 强边框，最显眼）/ `underlined`（仅底部一条线）。

## 固定 rows

不传 `minRows` / `maxRows` 时用固定 `rows`（默认 3），高度不随内容变化。

<LiveDemo code={`<Textarea rows={5} placeholder="固定 5 行高" />`}>
  <Textarea rows={5} placeholder="固定 5 行高" />
</LiveDemo>

## 自适应 Auto-size

`minRows` / `maxRows` 自动打开自适应模式：高度跟随内容，达到上限后出现滚动条。

<LiveDemo code={`<Textarea
  minRows={2}
  maxRows={6}
  placeholder="空时 2 行；继续输入会增长到最多 6 行然后滚动。"
/>`}>
  <Textarea
    minRows={2}
    maxRows={6}
    placeholder="空时 2 行；继续输入会增长到最多 6 行然后滚动。"
  />
</LiveDemo>

## 字数统计 showCount

`showCount` 需要配合 `maxLength`；右下角显示 `n/max`，接近上限时变 warning 色，超过时变 danger 色。

<LiveDemo code={`<Textarea
  showCount
  maxLength={80}
  defaultValue="试着输入超过 80 个字符看看变化。"
/>`}>
  <Textarea
    showCount
    maxLength={80}
    defaultValue="试着输入超过 80 个字符看看变化。"
  />
</LiveDemo>

## 受控用法

受控 + 自适应 + 字数统计的完整示例：

<LiveDemo previewSource="children" code={`import { useState } from 'react';
import { Textarea } from '@timeui/react';

export function FeedbackForm() {
  const [value, setValue] = useState('');
  return (
    <Textarea
      label="反馈"
      description="按 Enter 换行；最多 120 字。"
      value={value}
      onChange={setValue}
      minRows={3}
      maxRows={8}
      maxLength={120}
      showCount
      isFullWidth
    />
  );
}`}>
  <TextareaDemo />
</LiveDemo>

  `ref` 指向原生 `<textarea>`。`Enter` 不提交表单（符合原生行为）；`Escape` 也**不**清空 value（多行场景误触代价太高，行为与 Input 有意不同）。字数统计可见时通过 `aria-describedby` 指向 sr-only 节点，提供 "42 of 80 characters used" 的可读描述。所有过渡遵循 `prefers-reduced-motion`。
</Callout>
