# Empty

A placeholder for empty data sets, no-result states, and request errors: illustration + copy + optional action button. Four built-in image presets (`default` / `search` / `error` / `no-data`), five sizes, and `variant="inline"` for compact card-embedded use.

## Basic usage

The minimal form: pass `title` + `description`, optionally a primary CTA in `actions`.

<LiveDemo code={`<Empty
  title="Nothing here yet"
  description="Create your first project to get started."
  actions={<Button color="primary">New project</Button>}
/>`}>
  <Empty
    title="Nothing here yet"

  />
</LiveDemo>

## Image preset

Without `image`, you get `default`. The other three presets ship as built-in SVGs for the most common scenarios. For brand artwork, pass `image={<MyArt />}`.

## Sizes

`xs` / `sm` / `md` (default) / `lg` / `xl`. `xs` and `sm` fit cards and drawers; `lg` and `xl` fill a blank page.

## variant="inline"

A single-row empty state: image + one line of text + optional actions, laid out horizontally. Common in "no rows" rows of a table.

```tsx
<Empty
  variant="inline"
  image="no-data"
  title="No results in this view"
  actions={<Button size="sm" variant="ghost">Reset filters</Button>}
/>
```

## Custom children

If the default layout is too rigid, pass `children` to take over the body slot.

```tsx
<Empty image={<MyArt />}>
  <Heading level={3}>Welcome aboard</Heading>
  <Text muted>Three quick steps to set things up.</Text>
  <Steps items={[...]} />
</Empty>
```
