# Pagination

Page navigation that derives its layout from `total` + `pageSize` and renders the collapsed page list. Three forms — `default`, `simple`, `mini` — plus optional jumper and page-size selector.

<Callout variant="info" title="Controlled vs uncontrolled">
  Pass `page` + `onPageChange` for the controlled form, or `defaultPage` for uncontrolled. **Pagination doesn't slice your data** — it tells you the current page and `pageSize`; fetching or slicing the corresponding rows is on you (see "Pairing with Table" below for the canonical pattern).
</Callout>

## Variants

`default` shows full page numbers + chevrons. `simple` shows a compact `current / total` summary with chevrons. `mini` is `simple` locked to `sm` size — perfect for card footers and sidebars.

<LiveDemo code={`<Stack spacing={20}>

  <Pagination variant="mini"    total={120} defaultPage={3} />
</Stack>`}>

## Sizes

Five tiers — `xs` / `sm` / `md` (default) / `lg` / `xl` — adjust button height and font size. The `mini` variant always uses `sm`.

## siblingCount

Number of page buttons rendered on **either side** of the current page, default `1`. A higher value reduces ellipses and reveals more direct jumps.

<LiveDemo code={`<Stack spacing={16}>
  <Pagination total={500} defaultPage={12} siblingCount={0} />
  <Pagination total={500} defaultPage={12} siblingCount={1} />
  <Pagination total={500} defaultPage={12} siblingCount={2} />
</Stack>`}>
  <Stack spacing={16}>

## Quick jumper

`showQuickJumper` adds a numeric input — press <kbd>Enter</kbd> to jump (the value is clamped to `[1, totalPages]`).

<LiveDemo code={`<Pagination total={500} defaultPage={1} showQuickJumper />`}>
  <Pagination total={500} defaultPage={1} showQuickJumper />
</LiveDemo>

## Page-size changer

Switching `pageSize` resets `page` to `1` to avoid landing on an out-of-range page. Customize the choices via `pageSizeOptions` (defaults to `[10, 20, 50, 100]`).

<LiveDemo code={`import { useState } from 'react';
import { Pagination } from '@timeui/react';

export function Demo() {
  const [page, setPage] = useState(3);
  const [pageSize, setPageSize] = useState(20);
  return (
    <Pagination
      total={248}
      page={page}
      pageSize={pageSize}
      onPageChange={setPage}
      onPageSizeChange={(n) => { setPageSize(n); setPage(1); }}
      showSizeChanger
      showQuickJumper
      pageSizeOptions={[10, 20, 50, 100]}
    />
  );
}`}>
  <PaginationFullDemo />
</LiveDemo>

<Callout variant="info" title="Accessibility">
  The root is a `<nav>`. The active page button carries `aria-current="page"`; each page button is labeled `aria-label="Page {n}"`. Prev/next become `disabled` at the boundaries. Hover transitions honor `prefers-reduced-motion`.
</Callout>
