# 通知 Toast

命令式弹出的轻量提示。先在应用根部包一层 `<ToastProvider>`，再通过 `useToast()` 或 module-level `toast` 单例发出。自动 5s 关闭、hover 时暂停、相同 id 自动 update、`prefers-reduced-motion` 退化为淡入。

<Callout variant="info" title="装在哪里">
  把 `<ToastProvider>` 放到应用最外层（例如 Next.js 的 root layout）。一个进程同时只渲染最近一次挂载的 Provider 的 toast；命令式 `toast.*()` 在 Provider 外调用会 no-op + dev warn。
</Callout>

## 安装方式

```tsx
// app/layout.tsx
import { ConfigProvider, ThemeProvider, ToastProvider } from '@timeui/react';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <ConfigProvider>
      <ThemeProvider mode="light">
        <ToastProvider placement="top-right">
          {children}
        </ToastProvider>
      </ThemeProvider>
    </ConfigProvider>
  );
}
```

## 基础用法

`useToast()` 返回 `ToastApi`，包含 `success` / `error` / `warning` / `info` / `loading` 五个快捷方法以及通用 `show`。每条 toast 默认 5s 自动关闭，hover 时暂停计时，移开继续。

## Promise 流转

`toast.promise(p, msgs)` 会立即弹出 loading toast，并在 promise resolve / reject 后自动 update 为 success / error。`success` / `error` 既可以是节点也可以是 `(value) => node` 函数。

<LiveDemo previewSource="children" code={`toast.promise(uploadFile(file), {
  loading: 'Uploading file…',
  success: (v) => \`Uploaded — \${v.url}\`,
  error: (e) => \`Failed: \${e.message}\`,
});`}>
  <ToastPromiseDemo />
</LiveDemo>

## 命令式 vs Hook

- 在 React 组件树内推荐用 `useToast()`，能跟随 Provider 重新挂载稳定取到 store。
- 在非 React 环境（如 fetch 拦截器、状态机回调）使用 module-level `toast`，它代理到最近一次挂载的 Provider。

<Callout variant="info" title="可访问性">
  每个 toast 渲染为 `role="status"`（`danger` 为 `role="alert"`），`aria-live="polite"`。键盘可通过 Tab 进入操作按钮 / 关闭按钮；hover 或键盘聚焦时自动暂停 dismiss 计时。
</Callout>
