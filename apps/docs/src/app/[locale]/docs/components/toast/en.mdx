# Toast

Imperative, lightweight notifications. Wrap your app once with `<ToastProvider>`, then fire toasts from anywhere via `useToast()` or the module-level `toast` singleton. Auto-dismiss after 5 s, pauses on hover, same-id calls update in place, and degrades to a fade under `prefers-reduced-motion`.

<Callout variant="info" title="Where to mount it">
  Mount `<ToastProvider>` at the very top of the tree (e.g. Next.js root layout). Only the most recently mounted Provider is bound to the imperative `toast` singleton; calls outside any Provider are no-ops with a dev warning.
</Callout>

## Setup

```tsx
// app/layout.tsx
import { ConfigProvider, ThemeProvider, ToastProvider } from '@timeui/react';

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <ConfigProvider>
      <ThemeProvider mode="light">
        <ToastProvider placement="top-right">
          {children}
        </ToastProvider>
      </ThemeProvider>
    </ConfigProvider>
  );
}
```

## Basic usage

`useToast()` returns the `ToastApi` — five shortcuts (`success` / `error` / `warning` / `info` / `loading`) plus the generic `show`. Each toast auto-dismisses after 5 s, pauses while hovered, and resumes on mouse leave.

## Promise flow

`toast.promise(p, msgs)` immediately shows a loading toast and updates it to success / error when the promise settles. `success` / `error` accept a node or a `(value) => node` function.

<LiveDemo code={`toast.promise(uploadFile(file), {
  loading: 'Uploading file…',
  success: (v) => \`Uploaded — \${v.url}\`,
  error: (e) => \`Failed: \${e.message}\`,
});`}>
  <ToastPromiseDemo />
</LiveDemo>

## Hook vs. singleton

- Inside React components, prefer `useToast()` — it follows Provider remounts.
- Outside React (fetch interceptors, state-machine callbacks), use the module-level `toast`; it proxies to the most recently mounted Provider.

<Callout variant="info" title="Accessibility">
  Each toast renders with `role="status"` (or `role="alert"` for `danger`), `aria-live="polite"`. Action and close buttons are reachable via Tab; hovering or focusing the toast pauses the dismissal timer.
</Callout>
