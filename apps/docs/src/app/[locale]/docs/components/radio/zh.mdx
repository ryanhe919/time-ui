# 单选按钮 Radio

单选。`Radio` **必须**放在 `RadioGroup` 内部——Group 通过 Context 向每个 Radio 注入共享的 `name` 与当前 `value`，保证 HTML 原生 radio 组语义正确、键盘箭头切换行为可用。

## 基础用法

<LiveDemo code={`<RadioGroup label="性别" defaultValue="female">
  <Radio value="female">女</Radio>
  <Radio value="male">男</Radio>
  <Radio value="other">其他</Radio>
</RadioGroup>`}>
  <RadioGroup label="性别" defaultValue="female">
    <Radio value="female">女</Radio>
    <Radio value="male">男</Radio>
    <Radio value="other">其他</Radio>
  </RadioGroup>
</LiveDemo>

<Callout variant="info" title="可访问性">
  RadioGroup 根节点是 `<fieldset>` + `<legend>`（或 `role="radiogroup"` + `aria-labelledby`）。键盘支持：Tab 进入当前选中项，`↑ / ↓ / ← / →` 在组内切换（原生 radio 行为）；禁用的项会被跳过。Radio 单独使用（脱离 RadioGroup）时 dev 环境会在控制台警告——请直接换成原生 `<input type="radio">`。
</Callout>
