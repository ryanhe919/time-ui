# 搜索 Search

Pill 形状的"搜索触发器"——视觉上像输入框，**语义上是 `<button>`**。点击后由调用方自行打开 ⌘K 命令面板 / 搜索弹层。占位文案默认走 `useI18n()`，跟随当前 locale 自动切换。

<Callout variant="info" title="搭配 SearchDialog 使用">
  `Search` 本身**不接受文字输入**——它是一个触发器按钮。真正承载输入框、过滤、键盘导航、结果列表的是搭档组件 [`SearchDialog`](#searchdialog)。这种"⌘K 命令面板"模式被 Apple、Vercel、Tailwind、Linear 等文档站广泛采用。
</Callout>

## 最佳实践

- 顶栏的 `Search` 永远**不要**携带 `value`——它不是输入框，语义上应该只有 `placeholder` + `onClick`。
- 命令面板部分直接用 `SearchDialog` 即可，已经内置首次自动 focus、Esc 关闭、`role="dialog"` + `aria-modal="true"`、键盘上下导航、Enter 选中、滚动条美化等行为。
- 如果你的场景只需要一个常规搜索输入，而不是命令面板，请直接用原生 `<input type="search">`。

## SearchDialog

⌘K 命令面板对话框。和 `Search` 触发按钮搭配：`Search` 负责"打开"，`SearchDialog` 负责"输入 + 过滤 + 选中"。

### 完整搭配示例

`SearchDialog` 自带 `shortcut="mod+k"`，组件内部就会监听 ⌘K（Mac）/ Ctrl K（其它），不再需要手动写 `useEffect`。

<LiveDemo previewSource="children" code={`import { useState } from 'react';
import { Search, SearchDialog } from '@timeui/react';

export function CommandPalette() {
  const [open, setOpen] = useState(false);
  return (
    <>
      <Search shortcut="⌘K" onClick={() => setOpen(true)} />
      <SearchDialog
        isOpen={open}
        onOpenChange={setOpen}
        shortcut="mod+k"
        items={ITEMS}
        placeholder="搜索文档…"
        onSelect={(item) => router.push(item.href)}
      />
    </>
  );
}`}>
  <SearchDialogDemo />
</LiveDemo>

### 关键行为

- **位置**：对话框默认横向 + 纵向居中；传入 `topOffset` 后改为按顶部偏移定位
- **尺寸**：`width` 默认 `min(620px, 92vw)`；结果列表 `maxListHeight` 默认 `min(420px, 52vh)`，超过出现美化滚动条
- **键盘**：上下方向键导航（自动跳过 disabled 项）、Home/End 跳首尾、Enter 选中、Esc 关闭
- **过滤**：默认对 `label` + `hint` 做大小写无关子串匹配；传 `filter` 完全覆盖（远端搜索时返回 `() => true` 禁用本地过滤）
- **分组**：`sections` 优先于 `items`，每个 section 可有 `title`
- **加载态**：`isLoading` 显示 spinner + `loadingMessage`
- **快捷键**：`shortcut="mod+k"` 内置全局监听，自动 toggle `isOpen`
