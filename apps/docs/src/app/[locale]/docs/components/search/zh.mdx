# 搜索 Search

Pill 形状的"搜索触发器"——视觉上像输入框，实际上是 `<button>`。点击后由调用方自行打开 ⌘K 命令面板 / 搜索弹层。占位文案默认走 `useI18n()`，跟随当前 locale 自动切换。

## 基础用法

<LiveDemo code={`<Search />`}>
  <Search />
</LiveDemo>

## 带快捷键提示

`shortcut` 在右侧渲染一个 `<kbd>` 标签，常见值是 `⌘K` / `Ctrl K`。

<LiveDemo code={`<Search placeholder="搜索文档…" shortcut="⌘K" />`}>
  <Search placeholder="搜索文档…" shortcut="⌘K" />
</LiveDemo>

<Callout variant="tip" title="为什么是按钮，不是输入框？">
  现代文档站普遍把搜索做成 ⌘K 命令面板（Apple、Vercel、Tailwind、Linear），顶栏的"搜索框"只负责打开面板。`Search` 与这个心智模型对齐，本身不接受输入。需要真正的输入字段时使用原生 `<input type="search">`。
</Callout>
