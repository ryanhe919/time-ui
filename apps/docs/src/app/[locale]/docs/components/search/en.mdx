# Search

A pill-shaped **search trigger** — visually an input, **semantically a `<button>`**.
Clicking it opens a command palette / search dialog (your responsibility).
The placeholder defaults to `useI18n().search.placeholder` and follows the
active locale automatically.

<Callout variant="info" title="Pair it with SearchDialog">
  `Search` does **not** accept text input — it's a trigger button. The actual
  editable input, filtering, keyboard navigation, and result list live in its
  partner component [`SearchDialog`](#searchdialog). This "⌘K command palette"
  pattern is the same approach used by Apple, Vercel, Tailwind, and Linear.
</Callout>

## Best practices

- Never pass `value` to `Search` — it's a button, not an input.
- For the command palette layer use `SearchDialog` directly — it ships with auto-focus on open, <kbd>Esc</kbd> to close, `role="dialog"` + `aria-modal="true"`, arrow-key navigation, Enter selection, and a polished scrollbar.
- For a conventional search field (not a command palette), use a native `<input type="search">`.

## SearchDialog

The ⌘K command palette dialog. Pairs with the `Search` trigger: `Search` opens it, `SearchDialog` handles input + filtering + selection.

### End-to-end pairing

`SearchDialog` accepts a built-in `shortcut="mod+k"` so the dialog binds the global ⌘K (Mac) / Ctrl K (other) keypress itself — no manual `useEffect` needed.

<LiveDemo previewSource="children" code={`import { useState } from 'react';
import { Search, SearchDialog } from '@timeui/react';

export function CommandPalette() {
  const [open, setOpen] = useState(false);
  return (
    <>
      <Search shortcut="⌘K" onClick={() => setOpen(true)} />
      <SearchDialog
        isOpen={open}
        onOpenChange={setOpen}
        shortcut="mod+k"
        items={ITEMS}
        placeholder="Search docs…"
        onSelect={(item) => router.push(item.href)}
      />
    </>
  );
}`}>
  <SearchDialogDemo />
</LiveDemo>

### Key behaviour

- **Position**: centered both horizontally and vertically by default. Pass `topOffset` to switch to top-offset positioning.
- **Sizing**: `width` defaults to `min(620px, 92vw)`; the result list `maxListHeight` defaults to `min(420px, 52vh)` and shows a polished scrollbar when overflowing.
- **Keyboard**: arrow keys navigate (skipping disabled), Home/End jump to ends, Enter selects, Esc closes.
- **Filter**: case-insensitive substring match on `label` + `hint` by default. Pass a custom `filter` to override (return `() => true` to disable local filtering for remote search).
- **Sections**: `sections` win over `items` and may carry an optional `title`.
- **Loading**: `isLoading` shows a spinner + `loadingMessage`.
- **Shortcut**: `shortcut="mod+k"` binds the global key; the component toggles `isOpen` itself.
