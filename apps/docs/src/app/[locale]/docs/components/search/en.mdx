# Search

A pill-shaped *search trigger* — visually an input, semantically a `<button>`.
Clicking it opens a command palette / search dialog (your responsibility).
The placeholder defaults to `useI18n().search.placeholder` and follows the
active locale automatically.

## Basic usage

<LiveDemo code={`<Search />`}>
  <Search />
</LiveDemo>

## With shortcut hint

`shortcut` renders a `<kbd>` chip on the right — commonly `⌘K` or `Ctrl K`.

<Callout variant="tip" title="Why a button, not an input?">
  Modern docs sites (Apple, Vercel, Tailwind, Linear) implement search as a
  `⌘K` command palette — the visible "search box" only opens the palette.
  `Search` mirrors this mental model and does not accept text input. For an
  actual editable field, use a native `<input type="search">`.
</Callout>
