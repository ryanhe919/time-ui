# 日期时间选择 Date Time Picker

`DateTimePicker` 在 `DatePicker` 的基础上横向拼接了时间列，让一个控件同时承担年月日与时分秒。分钟、秒都是**可选择性开放**——被关闭的字段在最终 `Date` 中恒为 `0`，因此调用方拿到的永远是一个完整的 `Date` 对象。

<Callout variant="info" title="左日历、右时间">
  面板复用共享的 `CalendarPanel`（键盘、min/max、`isDateUnavailable` 完全一致），右侧拼接 `TimePanel` —— 小时 / 分钟 / 秒三列可选 `listbox`，`is12Hour` 打开时再加一列 AM/PM。底部 `[此刻] [清除] [确定]`：面板内所有交互先落入 draft，只有点 **确定** 才会触发 `onChange`，避免你拨动时间列时触发一堆意外回调。
</Callout>

## 基本用法

默认显示小时 + 分钟列，秒恒为 `0`。`isClearable` 同时在输入框和底部显示清除按钮。

<LiveDemo previewSource="children" code={`import { useState } from 'react';
import { DateTimePicker } from '@timeui/react';

export function Demo() {
  const [value, setValue] = useState<Date | null>(null);
  return (
    <DateTimePicker
      value={value}
      onChange={setValue}
      placeholder="选择日期时间"
      isClearable
    />
  );
}`}>
  <DateTimePickerBasicDemo />
</LiveDemo>

## 选择性开放分 / 秒

通过 `showMinute`（默认 `true`）与 `showSecond`（默认 `false`）开关时间列。**被隐藏的字段在提交时强制置 0** —— 这正是"可选择性开放"的语义：你想要哪一级精度，就开哪一列，不用担心下游拿到一个多余的 `getSeconds() === 37`。

<LiveDemo previewSource="children" code={`// 仅时 —— 分 / 秒恒为 0
<DateTimePicker showMinute={false} />

// 时 + 分（默认）
<DateTimePicker />

// 时 + 分 + 秒
<DateTimePicker showSecond />`}>
  <DateTimePickerGranularityDemo />
</LiveDemo>

## 12 小时制

`is12Hour` 追加一列 AM/PM。对外 `value` 仍是原生 `Date`（内部始终 24 小时制），只是 listbox 渲染与格式化字符串会变。

```tsx
<DateTimePicker is12Hour isClearable />
```

## 步长

`hourStep` / `minuteStep` / `secondStep`（默认 `1`）会稀疏化对应列的选项 —— 用于预约窗口或日志聚合粒度很方便。

```tsx
<DateTimePicker minuteStep={15} secondStep={10} />
```

## 提交流程：draft + 确定

与 `DatePicker` "点一下就关"不同，`DateTimePicker` 把面板当成一个 staging 区。点击日期或拨动时间列只改 draft，只有点 **确定** 才会触发 `onChange`。如果你更想要即点即生效，可以自己用 `isOpen` / `onOpenChange` 和外部 state 驱动。

底部按钮：
- **此刻**：把 draft 填为"今天 + 当前时间"（仍受 `minValue` / `maxValue` 约束）。
- **清除**（仅当 `isClearable`）：清空 value 并关闭面板。
- **确定**：提交 draft 并关闭面板。

## 本地化与格式

- `locale`：传给 `Intl` 的 BCP-47 标记。
- `format(d)` / `parse(s)`：自定义输入框的展示与解析。默认格式 `YYYY-MM-DD HH:mm`（`showSecond` 打开时追加 `:ss`，`is12Hour` 打开时追加 ` AM/PM`）；默认解析器同时宽容地接收 ISO-8601。
