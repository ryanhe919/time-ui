# 提示 Tooltip

反色质感的轻量浮层提示。复用 Popover 的 12 种 placement 与定位算法，但配色硬编码为反色（light 模式深底白字 / dark 模式浅底深字），仅支持 `hover` + `focus`，`pointer-events: none`，触摸屏自动隐藏。自带 warm-up 行为：刚关闭一个 tooltip 后短时间内打开下一个会跳过进入延迟。

<Callout variant="info" title="与 Popover 的核心区别">
  Tooltip = 反色 + 简短文本 + 不可交互（`pointer-events: none`，鼠标移到 tooltip 上不会让它继续展开）。它没有 header / footer / 关闭按钮、不支持 click 触发，触摸屏（`@media (hover: none)`）下完全不显示。需要在浮层里放按钮 / 输入框 / 链接列表？请用 [Popover](./popover)。
</Callout>

## 基础用法

把任意一个 `ReactElement`（必须是单个）作为 `children` 传入，组件会通过 `cloneElement` 注入 `ref`、`mouseenter` / `mouseleave` / `focus` / `blur` 事件以及 `aria-describedby`。

<LiveDemo code={`<Tooltip content="保存到本地">
  <Button>Save</Button>
</Tooltip>`}>
  <Tooltip content="保存到本地">
    <Button>Save</Button>
  </Tooltip>
</LiveDemo>

## 方位 placement

12 种 placement 全部继承自 Popover：`top` / `bottom` / `left` / `right` 四主向 + `-start` / `-end` 对齐变体。Tooltip 的默认 placement 是 `top`。

  </Tooltip>
  <Tooltip content="right" placement="right">

  </Tooltip>

## 延迟与 warm-up

`openDelay` / `closeDelay` 控制 hover/focus 进入与离开到 tooltip 显隐之间的等待时间（ms）。组件内部维护一个模块级"上次关闭时间戳"——若距上次关闭不到 `warmThreshold`（默认 500ms），下一次打开会**跳过 openDelay** 立即显示。这模拟了 macOS 系统级 tooltip 的"批处理"体验：在一组按钮间快速划过时，提示无延迟连续切换。

<LiveDemo code={`<Flex gap={16}>
  <Tooltip content="120ms 延迟（默认）"><Button>Default</Button></Tooltip>
  <Tooltip content="600ms 延迟" openDelay={600}><Button>Slow</Button></Tooltip>
  <Tooltip content="瞬时显示" openDelay={0}><Button>Instant</Button></Tooltip>
</Flex>`}>
  <Flex gap={16}>
    <Tooltip content="120ms 延迟（默认）"><Button>Default</Button></Tooltip>
    <Tooltip content="600ms 延迟" openDelay={600}><Button>Slow</Button></Tooltip>
    <Tooltip content="瞬时显示" openDelay={0}><Button>Instant</Button></Tooltip>
  </Flex>
</LiveDemo>

## 手动控制 isOpen

传入 `isOpen` 后组件进入"完全受控"模式，**所有内部 hover / focus 触发逻辑都被跳过**，显隐完全由你决定。常用于"教程引导第几步现在 active"等程序驱动场景。

<LiveDemo code={`<Tooltip isOpen content="始终显示" placement="top">
  <Button>Always on</Button>
</Tooltip>`}>
  <Tooltip isOpen content="始终显示" placement="top">
    <Button>Always on</Button>
  </Tooltip>
</LiveDemo>

<Callout variant="info" title="可访问性">
  Tooltip panel 渲染为 `role="tooltip"`，并通过 `aria-describedby` 与 anchor 关联（与 anchor 已有的 `aria-describedby` 自动合并）。focus 触发保证键盘用户能看到提示；触摸屏（`@media (hover: none)`）下整个 panel `display: none`，避免影响触摸用户。`prefers-reduced-motion` 下取消入场动画。
</Callout>
