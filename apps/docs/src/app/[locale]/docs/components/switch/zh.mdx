# 开关 Switch

Apple HIG 风格的开关：圆形滑块、iOS 绿底色、带轻微阴影。**布尔开关**的首选——比 Checkbox 更适合"设置项"场景（立即生效、不需要"确认"）。

底层渲染一个隐藏的原生 `<input type="checkbox" role="switch">`，保留表单提交和屏幕阅读器支持；视觉 track/thumb 由 CSS 绘制。

## 图标 startContent / endContent

`startContent` 在开启时显示（滑块左侧），`endContent` 在关闭时显示（滑块右侧）——常用于"太阳 / 月亮"主题切换的视觉隐喻。

## 受控用法：设置项列表

iOS 风格的设置页典型场景——一个设置项一行，右侧 Switch。

<LiveDemo code={`import { useState } from 'react';
import { Switch } from '@timeui/react';

export function SettingsList() {
  const [state, setState] = useState({
    notifications: true,
    autoSync: true,
    beta: false,
  });
  return (
    <div>
      {Object.entries(state).map(([key, on]) => (
        <label key={key}>
          <span>{key}</span>
          <Switch
            isSelected={on}
            onChange={(v) => setState((p) => ({ ...p, [key]: v }))}
          />
        </label>
      ))}
    </div>
  );
}`}>
  <SwitchSettingsDemo />
</LiveDemo>

<Callout variant="info" title="可访问性">
  内部渲染 `<input type="checkbox" role="switch" aria-checked={isSelected}>`，天然有布尔语义且可被 Tab 聚焦。键盘：`Space` 切换（native），`Enter` 也切换（手动绑定以弥补 checkbox 的默认行为）。focus 态包裹整个 track 的 outline；`prefers-reduced-motion` 下滑块直接跳变，不做过渡动画。没有 label 时必须显式传 `aria-label`。
</Callout>
