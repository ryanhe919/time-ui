# Switch

Apple HIG-flavored toggle: a circular thumb on an iOS-green track with a soft shadow. The **go-to boolean control** for settings pages — it beats Checkbox whenever the change should feel immediate with no "confirm" step.

Internally it renders a hidden native `<input type="checkbox" role="switch">` so form submission and screen readers work out of the box; the visible track/thumb is pure CSS.

## Controlled usage: settings list

The textbook iOS-style settings page — one row per setting, Switch on the right.

<LiveDemo code={`import { useState } from 'react';
import { Switch } from '@timeui/react';

export function SettingsList() {
  const [state, setState] = useState({
    notifications: true,
    autoSync: true,
    beta: false,
  });
  return (
    <div>
      {Object.entries(state).map(([key, on]) => (
        <label key={key}>
          <span>{key}</span>
          <Switch
            isSelected={on}
            onChange={(v) => setState((p) => ({ ...p, [key]: v }))}
          />
        </label>
      ))}
    </div>
  );
}`}>
  <SwitchSettingsDemo />
</LiveDemo>

<Callout variant="info" title="Accessibility">
  The hidden input is `<input type="checkbox" role="switch" aria-checked={isSelected}>` — naturally boolean, Tab-focusable. Keyboard: `Space` toggles (native) and `Enter` also toggles (explicitly bound; checkbox normally ignores Enter). Focus ring wraps the entire track. `prefers-reduced-motion` makes the thumb jump instead of sliding. Always pass `aria-label` when no visible label is present.
</Callout>
