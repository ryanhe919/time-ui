# Table

A data-driven table: describe the columns via `columns`, pass rows via `data`. Built-in support for sorting, row selection, fixed columns, sticky headers, density, and loading / empty states.

<Callout variant="info" title="Controlled-sort contract">
  Table **does not mutate your `data`**. When the user clicks a sortable header, the component emits `onSortChange(sortDescriptor)` and the consumer is responsible for sorting and feeding `data` back. This matches React Aria / Material Table conventions and avoids holding a duplicate copy of large datasets.
</Callout>

## Sorting

Mark a column with `isSortable: true` to render a sortable header. Click cycles `asc → desc → none`. **The consumer performs the actual sort.**

<LiveDemo previewSource="children" code={`import { useMemo, useState } from 'react';
import { Table } from '@timeui/react';
import type { SortDescriptor } from '@timeui/react';

export function Demo() {
  const [sort, setSort] = useState<SortDescriptor | undefined>({ columnKey: 'signups', direction: 'desc' });
  const sorted = useMemo(() => {
    if (!sort) return ROWS;
    return [...ROWS].sort((a, b) => {
      const av = a[sort.columnKey], bv = b[sort.columnKey];
      const cmp = av > bv ? 1 : av < bv ? -1 : 0;
      return sort.direction === 'asc' ? cmp : -cmp;
    });
  }, [sort]);

  return (
    <Table
      columns={[
        { columnKey: 'name', title: 'Name', isSortable: true },
        { columnKey: 'role', title: 'Role', isSortable: true },
        { columnKey: 'signups', title: 'Sign-ups', align: 'right', isSortable: true },
      ]}
      data={sorted}
      sortDescriptor={sort}
      onSortChange={setSort}
    />
  );
}`}>
  <TableSortableDemo />
</LiveDemo>

## Visual variant

Four visual strategies, **all built from the existing tokens — they coexist without clashing**:

- `enclosed` (default) — outer radius + container hairline + muted header bg. Apple Settings card vibe; ideal as a self-contained data block on the page.
- `divided` — no outer frame, header keeps only a strong bottom hairline + tightened letter-spacing. Apple Mail list vibe; recedes inside body copy.
- `grid` — `enclosed` plus hairlines between columns. Numbers / report vibe; great for dense fields.
- `quiet` — no border, no divider, no background; only row hover reveals separation. The most restrained form, best for documentation / reading contexts.

<Callout variant="info" title="How variant interacts with other visual switches">
  - `hasBorder` is honored only when `variant="enclosed"`; it is forced off for the others.
  - `isStriped`, `isStickyHeader`, and fixed columns all behave as expected across every variant.
  - For dense data with `quiet`, prefer `density="comfortable"` so the extra row padding replaces the missing dividers.
</Callout>

## Custom cells via column.render

`render(row, index)` takes over a cell entirely — drop in tags, avatars, buttons, links, rich text. Marking a column `isInteractive` prevents its clicks from bubbling to `onRowClick`.

<LiveDemo previewSource="children" code={`const COLUMNS = [
  { columnKey: 'name', title: 'Name' },
  {
    columnKey: 'status',
    title: 'Status',
    render: (row) => <Tag color={row.status === 'active' ? 'success' : 'muted'}>{row.status}</Tag>,
  },
  {
    columnKey: 'actions',
    title: '',
    isInteractive: true,
    render: (row) => <Button size="sm" onClick={() => alert(row.name)}>Edit</Button>,
  },
];

<Table columns={COLUMNS} data={ROWS} />`}>

## Pairing with Pagination

The canonical client-side pagination pattern: keep `page` + `pageSize` in state, slice the rows for the current page, hand them to `<Table data>`.

<LiveDemo previewSource="children" code={`import { useMemo, useState } from 'react';
import { Pagination, Table } from '@timeui/react';

export function Demo() {
  const [page, setPage] = useState(1);
  const [pageSize, setPageSize] = useState(10);
  const pageRows = useMemo(() => {
    const start = (page - 1) * pageSize;
    return ALL_ORDERS.slice(start, start + pageSize);
  }, [page, pageSize]);

  return (
    <>
      <Table columns={COLS} data={pageRows} rowKey="id" />
      <Pagination
        total={ALL_ORDERS.length}
        page={page}
        pageSize={pageSize}
        onChange={setPage}
        onPageSizeChange={(n) => { setPageSize(n); setPage(1); }}
        showSizeChanger
      />
    </>
  );
}`}>
  <TableWithPaginationDemo />
</LiveDemo>

<Callout variant="info" title="Accessibility">
  Renders a native `<table>` with `<thead>` / `<tbody>`. Sortable headers expose `aria-sort`; selectable rows expose `aria-selected`. Always provide an `aria-label` so the table has an accessible name. Hover and sort-icon transitions honor `prefers-reduced-motion`.
