# 表格 Table

数据驱动的表格：通过 `columns` 描述列、`data` 提供行数据。原生支持排序、行选择、固定列、sticky 表头、密度切换、loading / empty 状态。

<Callout variant="info" title="受控排序契约">
  Table **不会修改你的 `data`**。当用户点击排序表头时，组件只触发 `onSortChange(sortDescriptor)`，由消费方根据新的 `sortDescriptor` 自行排序数据再传回 `data`。这与 React Aria / Material Table 的契约一致，避免组件持有大量数据副本。
</Callout>

## 排序 isSortable

把列标为 `isSortable: true` 即在表头显示排序按钮。点击循环：`asc → desc → 无`。**消费方负责实际 sort**。

<LiveDemo previewSource="children" code={`import { useMemo, useState } from 'react';
import { Table } from '@timeui/react';
import type { SortDescriptor } from '@timeui/react';

export function Demo() {
  const [sort, setSort] = useState<SortDescriptor | undefined>({ columnKey: 'signups', direction: 'desc' });
  const sorted = useMemo(() => {
    if (!sort) return ROWS;
    return [...ROWS].sort((a, b) => {
      const av = a[sort.columnKey], bv = b[sort.columnKey];
      const cmp = av > bv ? 1 : av < bv ? -1 : 0;
      return sort.direction === 'asc' ? cmp : -cmp;
    });
  }, [sort]);

  return (
    <Table
      columns={[
        { columnKey: 'name', title: 'Name', isSortable: true },
        { columnKey: 'role', title: 'Role', isSortable: true },
        { columnKey: 'signups', title: 'Sign-ups', align: 'right', isSortable: true },
      ]}
      data={sorted}
      sortDescriptor={sort}
      onSortChange={setSort}
    />
  );
}`}>
  <TableSortableDemo />
</LiveDemo>

## 视觉风格 variant

四种视觉策略，**全部基于现有 token，互相之间风格自洽**：

- `enclosed`（默认）— 外圆角 + 容器 hairline + header muted bg。Apple Settings 卡片质感，适合作为页面里的"独立数据块"。
- `divided` — 无外框，header 仅保留底部 hairline strong + 强化 letter-spacing。Apple Mail 列表质感，嵌入正文不抢注意力。
- `grid` — 在 `enclosed` 基础上为单元格之间也画 hairline。Numbers / 报表质感，适合密集字段。
- `quiet` — 无边无线无 bg，仅靠 row hover 揭示行。最克制的形态，适合文档 / 阅读场景。

<Callout variant="info" title="variant 与其他视觉开关的关系">
  - `hasBorder` 仅对 `variant="enclosed"` 生效；其它 variant 强制忽略容器边框。
  - `isStriped` / `isStickyHeader` / `fixed` 列在四种 variant 下都按预期工作。
  - 数据行较多时，`quiet` 建议搭配更大的 `density="comfortable"` 让行间留白替代分隔线。
</Callout>

## 自定义渲染 column.render

`render(row, index)` 完全接管该单元格的渲染——可以塞 Tag、Avatar、Button、链接、富文本。带 `isInteractive` 的列其点击不会冒泡到行 `onRowClick`。

<LiveDemo previewSource="children" code={`const COLUMNS = [
  { columnKey: 'name', title: 'Name' },
  {
    columnKey: 'status',
    title: 'Status',
    render: (row) => <Tag color={row.status === 'active' ? 'success' : 'muted'}>{row.status}</Tag>,
  },
  {
    columnKey: 'actions',
    title: '',
    isInteractive: true,
    render: (row) => <Button size="sm" onClick={() => alert(row.name)}>Edit</Button>,
  },
];

<Table columns={COLUMNS} data={ROWS} />`}>
  <TableCustomRenderDemo />
</LiveDemo>

## 与 Pagination 配合

典型的"客户端分页"模式：消费方用 `useState` 保存 `page` 与 `pageSize`，每次切换从全量数据切片，再传给 `<Table data>`。

<LiveDemo previewSource="children" code={`import { useMemo, useState } from 'react';
import { Pagination, Table } from '@timeui/react';

export function Demo() {
  const [page, setPage] = useState(1);
  const [pageSize, setPageSize] = useState(10);
  const pageRows = useMemo(() => {
    const start = (page - 1) * pageSize;
    return ALL_ORDERS.slice(start, start + pageSize);
  }, [page, pageSize]);

  return (
    <>
      <Table columns={COLS} data={pageRows} rowKey="id" />
      <Pagination
        total={ALL_ORDERS.length}
        page={page}
        pageSize={pageSize}
        onChange={setPage}
        onPageSizeChange={(n) => { setPageSize(n); setPage(1); }}
        showSizeChanger
      />
    </>
  );
}`}>
  <TableWithPaginationDemo />
</LiveDemo>
