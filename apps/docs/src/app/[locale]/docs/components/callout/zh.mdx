# 提示块 Callout

散落在正文中的**提示、告警、小贴士**。5 种语义 variant，自带字形图标与左色条，不可关闭——用于**静态**说明场景（需要可关闭/带按钮请考虑 Alert）。

## 不带标题

`title` 可选。省略后仅显示正文，适合一行短提示。

<LiveDemo code={`<Callout variant="info">这是一条不带标题的提示。</Callout>`}>
  <Callout variant="info">这是一条不带标题的提示。</Callout>
</LiveDemo>

## 自定义图标

传入 `icon` 可替换前置字形，传入 `false` 则完全隐藏图标列。

<LiveDemo code={`<Stack spacing={12}>
  <Callout variant="tip" icon="🛠" title="Custom icon">传入任意 ReactNode 作为图标。</Callout>
  <Callout variant="info" icon={false}>隐藏图标时，文字占满整行。</Callout>
</Stack>`}>
  <Stack spacing={12}>
    <Callout variant="tip" icon="🛠" title="Custom icon">传入任意 ReactNode 作为图标。</Callout>
    <Callout variant="info" icon={false}>隐藏图标时，文字占满整行。</Callout>
  </Stack>
</LiveDemo>

<Callout variant="info" title="可访问性">
  `variant="warning"` 与 `variant="danger"` 使用 `role="alert"`，其余使用 `role="status"` —— 屏幕阅读器会按严重性做相应提示。
</Callout>
