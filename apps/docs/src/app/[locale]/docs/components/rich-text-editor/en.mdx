# RichTextEditor

A WYSIWYG editor built on **TipTap** (ProseMirror) that emits HTML and slots into the same `size` / `variant` system as [`Input`](./input) / [`Textarea`](./textarea). The toolbar is fully composable — pick a preset (`'minimal' | 'basic' | 'full'`), pass your own `ToolbarItem[]`, or hide it entirely. Shipped behind the `@timeui/react/rich-text-editor` subpath export so TipTap and ProseMirror **never land in the main bundle** unless you import the editor.

## Basic usage

Controlled HTML state. Every keystroke fires `onChange(html)`; the chip below mirrors the current document length.

<LiveDemo previewSource="children" code={`import { useState } from 'react';
import { RichTextEditor } from '@timeui/react/rich-text-editor';

export function BasicEditor() {
  const [html, setHtml] = useState(
    '<p>Welcome to <strong>TimeUI</strong> RichTextEditor — try <em>formatting</em> some text.</p>',
  );
  return (
    <RichTextEditor
      aria-label="Basic editor"
      value={html}
      onChange={setHtml}
      placeholder="Start writing…"
    />
  );
}`}>
  <RichTextEditorBasicDemo />
</LiveDemo>

## Variants & sizes

Three visual recipes (`flat`, `bordered`, `faded`) and five size steps (`xs`, `sm`, `md`, `lg`, `xl`). They reuse the same field-style helpers as `Input` / `Textarea`, so spacing, focus ring, and invalid color all stay consistent.

## Toolbar

`toolbar` accepts a preset string, a custom `ToolbarItem[]`, or `false` to hide the bar entirely. Presets at a glance:

- `'minimal'` — `bold` / `italic` / `underline`
- `'basic'` (default) — inline marks + `h1`–`h3` + lists + `link`
- `'full'` — everything: inline marks, headings, lists, link, strike, blockquote, code, code block, horizontal rule, clear formatting, undo / redo

A custom array gives you per-button control; insert `'separator'` to draw a vertical divider.

<LiveDemo previewSource="children" code={`import { useState } from 'react';

## Hiding the toolbar

Pass `toolbar={false}` for a chrome-less editor — useful inside chat composers, comment fields, or anywhere the toolbar would steal focus from surrounding UI. Formatting still works through keyboard shortcuts (`Cmd/Ctrl+B`, `Cmd/Ctrl+I`, etc.).

## Extending with TipTap

Anything you pass via `extensions` is appended **after** the built-in set (`StarterKit`, `Underline`, `Link`, `Placeholder`). The example below adds a typography extension; toolbar buttons that target your custom node still need to be wired through the consumer (the editor exposes the `Editor` instance via `onCreate` for that).

```tsx
import { RichTextEditor } from '@timeui/react/rich-text-editor';
import Typography from '@tiptap/extension-typography';
import TaskList from '@tiptap/extension-task-list';
import TaskItem from '@tiptap/extension-task-item';

export function ExtendedEditor() {
  return (
    <RichTextEditor
      placeholder="Smart quotes, ellipses and task lists are now active."
      extensions={[Typography, TaskList, TaskItem.configure({ nested: true })]}
    />
  );
}
```

## Accessing the Editor instance

`onCreate` fires once the underlying TipTap `Editor` is ready. Stash the reference and call any TipTap command — focus, programmatic insertion, exporting to JSON, registering custom keymaps, etc.

```tsx
import { useRef } from 'react';
import type { Editor } from '@tiptap/react';
import { RichTextEditor } from '@timeui/react/rich-text-editor';

export function ProgrammaticEditor() {
  const editorRef = useRef<Editor | null>(null);

  return (
    <>
      <RichTextEditor
        defaultValue="<p>Hello there.</p>"
        onCreate={(editor) => {
          editorRef.current = editor;
        }}
      />
      <button
        type="button"
        onClick={() => {
          const editor = editorRef.current;
          if (!editor) return;
          editor.chain().focus().insertContent(' <strong>👋</strong>').run();
          // Any other TipTap command works the same way:
          // editor.getJSON(); editor.commands.setContent('…'); etc.
        }}
      >
        Insert wave
      </button>
    </>
  );
}
```

### `ToolbarItem` values

`'bold' | 'italic' | 'underline' | 'strike' | 'h1' | 'h2' | 'h3' | 'bulletList' | 'orderedList' | 'blockquote' | 'code' | 'codeBlock' | 'horizontalRule' | 'link' | 'clearFormat' | 'undo' | 'redo' | 'separator'`

<Callout variant="info" title="Bundle impact">
  TipTap is **not** bundled with `@timeui/react`. To use this component install the seven TipTap peers alongside it:

```bash
pnpm add @tiptap/core @tiptap/react @tiptap/pm \
  @tiptap/starter-kit @tiptap/extension-underline \
  @tiptap/extension-link @tiptap/extension-placeholder
```

Use one consistent Tiptap major across all seven packages: version 2.27.3 or newer on 2.x, or 3.30.4 or newer on 3.x. These minimum versions include the `mergeAttributes` security fix. Mixing Tiptap 2 and 3 packages causes incompatible extension types.

Import only from the dedicated subpath — `import { RichTextEditor } from '@timeui/react/rich-text-editor'` — so tree-shaking keeps TipTap out of pages that never render the editor.

</Callout>

<Callout variant="info" title="Accessibility">
  The container is `role="textbox"` with `aria-multiline="true"` plus `aria-disabled` / `aria-readonly` / `aria-invalid` mirroring the props. Provide `aria-label` (or wrap in a labelled `FormField`) when there is no visible label. Toolbar buttons are real `<button>` elements with `aria-pressed` for active marks. All keyboard shortcuts are inherited from TipTap (`Cmd/Ctrl+B`, `Cmd/Ctrl+I`, `Cmd/Ctrl+Z`, etc.) and remain available even when the toolbar is hidden.
</Callout>
