# 富文本编辑器 RichTextEditor

基于 **TipTap**（ProseMirror）的所见即所得编辑器，输出 HTML，与 [`Input`](./input) / [`Textarea`](./textarea) 共享同一套 `size` / `variant` 体系。Toolbar 完全可配——可直接选 preset（`'minimal' | 'basic' | 'full'`）、自定义 `ToolbarItem[]`，或彻底隐藏。组件通过 `@timeui/react/rich-text-editor` 独立 subpath 导出，**不引入富文本编辑器的页面里 TipTap 与 ProseMirror 不会进主 bundle**。

## 基础用法

受控的 HTML 状态。每次输入都会触发 `onChange(html)`，下方 chip 实时回显当前 HTML 长度。

<LiveDemo code={`import { useState } from 'react';
import { RichTextEditor } from '@timeui/react/rich-text-editor';

export function BasicEditor() {
  const [html, setHtml] = useState(
    '<p>Welcome to <strong>TimeUI</strong> RichTextEditor — try <em>formatting</em> some text.</p>',
  );
  return (
    <RichTextEditor
      aria-label="基础编辑器"
      value={html}
      onChange={setHtml}
      placeholder="开始书写…"
    />
  );
}`}>
  <RichTextEditorBasicDemo />
</LiveDemo>

## 样式 Variants 与尺寸 Sizes

三种视觉样式（`flat`、`bordered`、`faded`）+ 三档尺寸（`sm`、`md`、`lg`）。复用 `Input` / `Textarea` 同一组 field-style 工具，所以间距、聚焦环、invalid 配色完全一致。

## 工具条 Toolbar

`toolbar` 接受 preset 字符串、自定义 `ToolbarItem[]`，或 `false` 完全隐藏。预设速览：

- `'minimal'` —— `bold` / `italic` / `underline`
- `'basic'`（默认）—— inline marks + `h1`–`h3` + 列表 + `link`
- `'full'` —— 完整集合：inline marks、headings、列表、link、strike、blockquote、code、code block、horizontal rule、清除格式、undo / redo

数组形式让你逐个开关按钮；用 `'separator'` 插入竖向分隔线。

<LiveDemo code={`import { useState } from 'react';
import { SegmentedControl } from '@timeui/react';
import { RichTextEditor } from '@timeui/react/rich-text-editor';

export function ToolbarPresets() {
  const [preset, setPreset] = useState('basic');
  return (
    <>
      <SegmentedControl
        aria-label="Toolbar preset"
        value={preset}
        onChange={setPreset}
        options={[
          { value: 'minimal', label: 'minimal' },
          { value: 'basic', label: 'basic' },
          { value: 'full', label: 'full' },
        ]}
      />
      <RichTextEditor toolbar={preset} defaultValue="<p>Toolbar presets</p>" />
      <RichTextEditor
        toolbar={['bold', 'italic', 'separator', 'h1', 'h2', 'separator', 'link']}
        defaultValue="<p>自定义 toolbar</p>"
      />
    </>
  );
}`}>

</LiveDemo>

## 取消 toolbar

传 `toolbar={false}` 即可得到无 chrome 编辑区——适用于聊天 composer、评论框等不希望 toolbar 抢眼的场景。键盘快捷键（`Cmd/Ctrl+B`、`Cmd/Ctrl+I` 等）依然有效。

## 用 TipTap 扩展能力

通过 `extensions` 传入的扩展会拼接在内置集合（`StarterKit`、`Underline`、`Link`、`Placeholder`）之后。下方示例追加了 `Typography` 和 `TaskList`；如果自定义扩展需要对应的 toolbar 按钮，需自行通过 `onCreate` 拿到 `Editor` 实例并接管。

```tsx
import { RichTextEditor } from '@timeui/react/rich-text-editor';
import Typography from '@tiptap/extension-typography';
import TaskList from '@tiptap/extension-task-list';
import TaskItem from '@tiptap/extension-task-item';

export function ExtendedEditor() {
  return (
    <RichTextEditor
      placeholder="智能引号、省略号、任务列表已开启。"
      extensions={[
        Typography,
        TaskList,
        TaskItem.configure({ nested: true }),
      ]}
    />
  );
}
```

## 拿到 Editor 实例

底层 TipTap `Editor` 就绪后会触发 `onCreate`。把它存起来就能调任意 TipTap command——聚焦、程序化插入、导出 JSON、注册自定义 keymap，等等。

```tsx
import { useRef } from 'react';
import type { Editor } from '@tiptap/react';
import { RichTextEditor } from '@timeui/react/rich-text-editor';

export function ProgrammaticEditor() {
  const editorRef = useRef<Editor | null>(null);

  return (
    <>
      <RichTextEditor
        defaultValue="<p>Hello there.</p>"
        onCreate={(editor) => {
          editorRef.current = editor;
        }}
      />
      <button
        type="button"
        onClick={() => {
          const editor = editorRef.current;
          if (!editor) return;
          editor.chain().focus().insertContent(' <strong>👋</strong>').run();
          // 任意 TipTap command 都可以这么用：
          // editor.getJSON(); editor.commands.setContent('…'); 等。
        }}
      >
        插入挥手
      </button>
    </>
  );
}
```

### `ToolbarItem` 取值

`'bold' | 'italic' | 'underline' | 'strike' | 'h1' | 'h2' | 'h3' | 'bulletList' | 'orderedList' | 'blockquote' | 'code' | 'codeBlock' | 'horizontalRule' | 'link' | 'clearFormat' | 'undo' | 'redo' | 'separator'`

<Callout variant="info" title="Bundle 影响">
  TipTap **不会**被打进 `@timeui/react` 主 bundle。使用本组件时需自行安装这 7 个 TipTap peer：

```bash
pnpm add @tiptap/core @tiptap/react @tiptap/pm \
  @tiptap/starter-kit @tiptap/extension-underline \
  @tiptap/extension-link @tiptap/extension-placeholder
```

请只从专属 subpath 导入 —— `import { RichTextEditor } from '@timeui/react/rich-text-editor'` —— tree-shaking 才能确保不渲染编辑器的页面不引入 TipTap。
</Callout>

<Callout variant="info" title="可访问性">
  容器为 `role="textbox"` + `aria-multiline="true"`，并把 `isDisabled` / `isReadOnly` / `isInvalid` 同步到 `aria-disabled` / `aria-readonly` / `aria-invalid`。没有可见 label 时请提供 `aria-label`（或包到带 label 的 `FormField` 里）。Toolbar 按钮均为真实 `<button>`，激活的 mark 会带 `aria-pressed`。所有键盘快捷键沿用 TipTap 默认（`Cmd/Ctrl+B`、`Cmd/Ctrl+I`、`Cmd/Ctrl+Z` 等），即使 toolbar 隐藏也仍可用。
</Callout>
