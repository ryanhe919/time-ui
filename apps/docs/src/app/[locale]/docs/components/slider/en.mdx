# Slider

A continuous numeric input: drag a circular thumb along a track to pick a single value, or pick a range. Internally each thumb is a real `<input type="range">`, so keyboard (arrows / Home / End / PageUp / PageDown), screen readers, and native form submission work out of the box.

## Basic usage

Single horizontal value — the canonical "volume / progress" slider.

<LiveDemo code={`<Stack spacing={24} sx={{ width: 'min(420px, 100%)' }}>
  <Slider aria-label="Volume" defaultValue={30} />
  <Slider label="Volume" defaultValue={30} showValue />
</Stack>`}>
  <Stack spacing={24} sx={{ width: 'min(420px, 100%)' }}>
    <Slider aria-label="Volume" defaultValue={30} />
    <Slider label="Volume" defaultValue={30} showValue />
  </Stack>
</LiveDemo>

## Range

Pass `value` / `defaultValue` as a `[min, max]` tuple to switch into two-thumb mode. The thumbs constrain each other and cannot cross.

<LiveDemo code={`<Slider
  label="Price Range"
  max={1000}
  defaultValue={[100, 500]}
  showValue
  formatValue={(v) =>
    Array.isArray(v)
      ? \`US$\${v[0].toFixed(2)} – US$\${v[1].toFixed(2)}\`
      : \`US$\${v.toFixed(2)}\`
  }
/>`}>
  <SliderRangeDemo />
</LiveDemo>

## Vertical

`orientation="vertical"` puts the value above the track and the label below it — the traditional volume-bar shape. Use `trackLength` to control the track length (width when horizontal, height when vertical).

<LiveDemo code={`<Flex gap={32} align="center" justify="center">
  <Slider
    orientation="vertical"
    label="Volume"
    defaultValue={46}
    showValue
  />
  <Slider
    orientation="vertical"
    color="success"
    defaultValue={[20, 70]}
    showValue
    trackLength={200}
  />
</Flex>`}>
  <Flex gap={32} align="center" justify="center">
    <Slider orientation="vertical" label="Volume" defaultValue={46} showValue />
    <Slider orientation="vertical" color="success" defaultValue={[20, 70]} showValue trackLength={200} />
  </Flex>
</LiveDemo>

## Step

`step` controls both keyboard increments and pointer-drag snapping. Decimal `step` values are rounded to the same precision so floating-point drift doesn't leak into your state.

<LiveDemo code={`<Stack spacing={20} sx={{ width: 'min(420px, 100%)' }}>
  <Slider label="step=10" defaultValue={50} step={10} showValue />
  <Slider label="step=0.1" min={0} max={1} defaultValue={0.4} step={0.1} showValue />
</Stack>`}>
  <Stack spacing={20} sx={{ width: 'min(420px, 100%)' }}>
    <Slider label="step=10" defaultValue={50} step={10} showValue />

## Controlled

`onChange` fires on every value change; `onChangeEnd` fires once when the drag ends or a key is released — perfect for "commit once" flows.

<LiveDemo code={`import { useState } from 'react';
import { Slider } from '@timeui/react';

export function VolumeAndPrice() {
  const [vol, setVol] = useState(30);
  const [price, setPrice] = useState<[number, number]>([100, 500]);
  return (
    <>
      <Slider label="Volume" showValue value={vol} onChange={(v) => setVol(v as number)} />
      <Slider
        label="Price Range"
        max={1000}
        showValue
        formatValue={(v) =>
          Array.isArray(v)
            ? \`US$\${v[0].toFixed(2)} – US$\${v[1].toFixed(2)}\`
            : \`US$\${v.toFixed(2)}\`
        }
        value={price}
        onChange={(v) => Array.isArray(v) && setPrice(v)}
      />
    </>
  );
}`}>
  <SliderVolumeDemo />
</LiveDemo>

<Callout variant="info" title="Accessibility">
  Each thumb is a real `<input type="range">`, with `role="slider"`, `aria-valuemin/max/now`, keyboard stepping, and form submission for free. In range mode both thumbs are independently Tab-focusable and ship with "minimum"/"maximum" `aria-label` suffixes. `prefers-reduced-motion` disables the fill and thumb transitions.
</Callout>
