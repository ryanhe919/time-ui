# 复选框 Checkbox

单个可选框（含 indeterminate 中间态）；**CheckboxGroup** 提供多选组的状态管理、共享 `name`、统一的 label/error 承载。

## 基础用法

单 Checkbox 天然是一个 `<label>` 包住 `<input type="checkbox">`，点击 label 文字等价于点击指示器。

<LiveDemo code={`<Stack spacing={12}>
  <Checkbox defaultIsSelected>已选中</Checkbox>
  <Checkbox>未选中</Checkbox>
  <Checkbox isIndeterminate>Indeterminate（中间态）</Checkbox>
</Stack>`}>
  <Stack spacing={12}>
    <Checkbox defaultIsSelected>已选中</Checkbox>
    <Checkbox>未选中</Checkbox>
    <Checkbox isIndeterminate>Indeterminate（中间态）</Checkbox>
  </Stack>
</LiveDemo>

用于"部分选中"的语义，例如父级勾选框汇总一组子项的状态。

## CheckboxGroup 多选组

Group 负责维护 `value: string[]`，自动给每个子 Checkbox 注入 `name`，并在外层提供 label / description / errorMessage。

<LiveDemo code={`<CheckboxGroup label="兴趣爱好" description="可多选">

## Group 的错误态

Group 级别的 `errorMessage` 会走一次 `aria-describedby` 串联到 group；同时每个 Checkbox 的 `aria-invalid` 都会是 `true`。

<LiveDemo code={`<CheckboxGroup
  label="服务条款"
  errorMessage="请至少勾选一项以继续。"
  isRequired
>
  <Checkbox value="tos">我已阅读并同意用户协议</Checkbox>
  <Checkbox value="privacy">我已阅读并同意隐私政策</Checkbox>
</CheckboxGroup>`}>
  <CheckboxGroup label="服务条款" errorMessage="请至少勾选一项以继续。" isRequired>

    <Checkbox value="privacy">我已阅读并同意隐私政策</Checkbox>

<Callout variant="info" title="可访问性">
  单 Checkbox 用 `<label>` 包裹原生 `<input type="checkbox">`，天然有 accessible name，不需要额外 `aria-label`。Indeterminate 通过 `input.indeterminate = true` 设置，屏幕阅读器会读作 "mixed"。CheckboxGroup 根节点是 `<fieldset>` + `<legend>`（或 `role="group"` + `aria-labelledby`），支持键盘 Tab 进入，Space 切换。
</Callout>
