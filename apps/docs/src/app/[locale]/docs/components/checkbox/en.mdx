# Checkbox

A single check box (with an `indeterminate` tri-state) plus **CheckboxGroup** — a wrapper that manages a `string[]` selection, auto-wires a shared `name`, and renders a single label / description / errorMessage across the group.

## Basic usage

A `Checkbox` is a `<label>` wrapping the native `<input type="checkbox">`, so clicking the text or the indicator both toggle the value.

<LiveDemo code={`<Stack spacing={12}>

</Stack>`}>

## Group-level error

A group-level `errorMessage` hooks into `aria-describedby` on the group and flips every child's `aria-invalid` to `true`.

<Callout variant="info" title="Accessibility">
  Each `Checkbox` is a `<label>` wrapping a native `<input type="checkbox">`, giving it an implicit accessible name — no extra `aria-label` needed. Indeterminate is set imperatively via `input.indeterminate = true`; screen readers announce it as "mixed". `CheckboxGroup` renders `<fieldset>` + `<legend>` (or `role="group"` + `aria-labelledby` for ReactNode labels). Tab focuses the first checkbox and Space toggles.
</Callout>
