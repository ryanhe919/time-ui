# 卡片 Card

通用的容器原语：承载一段信息 / 一组控件。三种 variant（flat / bordered / elevated）、六种 color、五档 size、可选的 accent bar、可整卡 hover / pressable / 链接化。`CardHeader` / `CardBody` / `CardFooter` 是可选的结构子组件——只在需要语义化时才用。

<Callout variant="info" title="Card 还是 StatCard？">
  - **Card**：开放容器。内部可放任意内容，由你自己决定语义。
  - **StatCard**：KPI 专用派生组件，label + value + delta pill + 可选 trend，视觉与语义都已对齐。
</Callout>

## 基础用法

默认 `variant='bordered'`，配合 `CardHeader` / `CardBody` / `CardFooter` 组织内容。三个子组件都不是必须的——Card 自身就能包住任何 children。

<LiveDemo code={`<Card>
  <CardHeader title="项目 Aurora" subtitle="生产环境" />
  <CardBody>
    <Text size="sm" color="secondary">运行 12 天无异常。</Text>
  </CardBody>
  <CardFooter justify="end">
    <Button size="sm" variant="bordered">查看详情</Button>
  </CardFooter>
</Card>`}>
  <div style={{ width: 'min(360px, 100%)' }}>

      <CardFooter justify="end">
        <Button size="sm" variant="bordered">查看详情</Button>
      </CardFooter>
    </Card>
  </div>
</LiveDemo>

## 可按 Pressable

`isPressable` 让整卡变成一个可聚焦 / 可 Enter / Space 触发的目标，回调走 `onPress`；`isHoverable` 只给视觉反馈、不改键盘语义。`color='primary'` 决定 hover 时的边框 / 环色。

<LiveDemo code={`<Card isPressable color="primary" onPress={() => setCount(c => c + 1)}>
  <CardHeader title="可按卡片" subtitle="点击 / Enter / Space 触发 onPress" />
  <CardBody>
    <Text size="sm" color="secondary">已触发次数: <strong>{count}</strong></Text>
  </CardBody>
</Card>
<Card isHoverable>
  <CardHeader title="仅 hover" subtitle="isHoverable 只加视觉，没有键盘语义" />
</Card>`}>
  <CardPressableDemo />
</LiveDemo>

## 作为链接 Link

传入 `href` 会把根节点渲染成 `<a>`（除非用 `as` 强制覆盖），此时 `isPressable` 自动为真。`target='_blank'` 时若未显式传 `rel`，组件会自动补 `noopener noreferrer`。

<LiveDemo code={`<Card
  href="https://react.dev"
  target="_blank"
  rel="noreferrer"
  aria-label="阅读 React 文档"
  variant="elevated"
>
  <CardHeader title="React 官方文档" subtitle="react.dev ↗" />
  <CardBody>
    <Text size="sm" color="secondary">整卡都是一个 anchor，原生键盘行为。</Text>
  </CardBody>
</Card>`}>
  <div style={{ width: 'min(360px, 100%)' }}>
    <Card
      href="https://react.dev"
      target="_blank"
      rel="noreferrer"
      aria-label="阅读 React 文档"
      variant="elevated"
    >
      <CardHeader title="React 官方文档" subtitle="react.dev ↗" />
      <CardBody>
        <Text size="sm" color="secondary">整卡都是一个 anchor，原生键盘行为。</Text>
      </CardBody>
    </Card>
  </div>
</LiveDemo>

## 禁用 Disabled

`isDisabled` 与 `isPressable` 叠加时整卡降到 0.55 透明度、`cursor: not-allowed`、`aria-disabled='true'`，键盘事件与 `onPress` 都被拦下。

<LiveDemo code={`<Card
  isPressable
  isDisabled
  color="primary"
  onPress={() => console.log('这条不会触发')}
>
  <CardHeader title="已禁用" subtitle="onPress 不会被触发" />
</Card>`}>
  <div style={{ width: 'min(320px, 100%)' }}>
    <Card isPressable isDisabled color="primary">
      <CardHeader title="已禁用" subtitle="onPress 不会被触发" />
    </Card>
  </div>
</LiveDemo>

## 注意事项

<Callout variant="info" title="color 并非总是可见">
  Card 默认 neutral 外观。`color` 只在以下两种情况影响视觉：1）`accentBar !== 'none'` 时决定色条颜色；2）`isPressable` / `isHoverable` 时决定 hover 的边框 / 环 / 背景色。纯静态 `<Card color='primary'>` 看起来与 `color='default'` 一致。
</Callout>

<Callout variant="info" title="onPress vs onClick">
  **推荐用 `onPress`**：组件会把鼠标点击与键盘 Enter/Space 都归一化成 `onPress`。`onClick` 仍然保留透传原生 click，但键盘触发时不会合成原生 click 事件。被禁用时 `onPress` 不触发，但 `onClick` 仍可能被原生事件触发——所以 **`isDisabled` + 业务回调请一律挂 `onPress`**，语义更稳。
</Callout>

<Callout variant="info" title="整卡可按时不要再在 Footer 里放 primary 按钮">
  整卡已经是一个聚焦目标，再在 Footer 放一个 primary Button 会产生双聚焦点；用户不知道回车会触发哪一个。需要两个动作时，建议把主动作放在 Footer（Card 本体不 pressable），或整卡 pressable 但 Footer 只放次级链接。
</Callout>
