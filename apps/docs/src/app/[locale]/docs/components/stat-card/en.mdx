# StatCard

A KPI-shaped card. Fixed label + value layout, delta pill with an arrow-tick animation, optional icon slot / description / trend area / skeleton state. All of Card's governance props (variant / color / size / radius / accentBar / pressable / href) pass through to the underlying `Card`.

<Callout variant="info" title="Card vs. StatCard">
  - Single KPI (value + delta + optional sparkline)? Use **StatCard** — no layout work needed.
  - Anything else — forms, tables, structured blocks? Reach for **Card**.
</Callout>

## Basic usage

`label` + `value` is the minimal form. Label gets uppercase + letter-tracking (automatically disabled when the string contains CJK), and value uses tabular-nums with slashed-zero.

<LiveDemo code={`<StatCard label="ACTIVE USERS" value="12,480" />`}>
  <div style={{ width: 'min(280px, 100%)' }}>
    <StatCard label="ACTIVE USERS" value="12,480" />
  </div>
</LiveDemo>

## Delta — three directions

`delta.direction` is `'up' | 'down' | 'flat'`. Polarity defaults to `'auto'` — up = positive (green), down = negative (red), flat = neutral grey. Flip the mapping (e.g. churn: less is better) by passing `polarity='negative'`. The button below swaps snapshots so the arrow-tick animation replays.

<LiveDemo code={`<StatCard label="MRR" value="$128,402" delta={{ value: '+12.4%', direction: 'up' }} />
<StatCard label="CHURN RATE" value="2.1%" delta={{ value: '-0.4pp', direction: 'down' }} />
<StatCard label="NPS" value="54" delta={{ value: '0', direction: 'flat' }} />`}>
  <StatCardDeltaDemo />
</LiveDemo>

## With icon

`icon` accepts any ReactNode; it renders inside a tinted container whose size follows `size`. `iconPlacement` switches between `'start'` (default) and `'end'`. The icon wrapper is `aria-hidden` and never appears in the accessibility tree.

<LiveDemo code={`<StatCard
  label="ORDERS"
  value="3,248"
  icon={<span aria-hidden>O</span>}
  iconPlacement="start"
/>
<StatCard
  label="REVENUE"
  value="$1.2M"
  icon={<span aria-hidden>$</span>}
  iconPlacement="end"

## Pressable / link

StatCard passes through `isPressable` / `isHoverable` / `href` so the whole card can navigate or fire `onPress` — classic drill-down cards on dashboards. Supplying `href` renders the root as `<a>`.

<LiveDemo code={`<StatCard
  isHoverable
  href="#revenue"
  aria-label="Go to revenue details"
  label="REVENUE"
  value="$1.2M"
  description="Click to drill down"
  delta={{ value: '+14%', direction: 'up' }}
  accentBar="start"
  color="primary"
/>
<StatCard
  isPressable
  isHoverable
  onPress={() => console.log('pressed')}
  label="ORDERS"
  value="3,248"
  description="Press fires onPress"
  delta={{ value: '-2.1%', direction: 'down' }}
  variant="elevated"
/>`}>
  <StatCardPressableDemo />
</LiveDemo>

## Caveats

<Callout variant="info" title="delta aria-label falls back when value is not a string">
  When `delta.value` is a plain string the screen reader hears the full sentence ("Up 12.4%"). If you pass a ReactNode (e.g. rich text), the component cannot extract text, and the aria-label falls back to just the direction word ("Up" / "Down" / "Flat"). For complete announcements pass `sr={{ deltaLabel: 'Up 12.4 percentage points' }}` explicitly.
</Callout>

<Callout variant="info" title="CJK labels auto-disable uppercase">
  If the label contains CJK characters the component drops uppercase + letter-tracking and bumps the font slightly so CJK renders legibly. Mixed-case Latin labels keep the uppercase treatment — use English strings like "REVENUE" or "MRR" when you want that effect.
</Callout>

<Callout variant="info" title="Do not nest another focus target inside a pressable StatCard">
  A StatCard usually holds only value / delta / optional trend. If you inject a `<Button>` / `<a>` inside `description` or `trend`, it competes with the outer pressable surface for focus. Use a secondary Card / menu for the sub-entry instead.
</Callout>

<Callout variant="info" title="Accessibility">
  The delta pill carries `role='status'` plus an aria-label built from the i18n dictionary (e.g. `Up {value}`) or overridden via `sr.deltaLabel`. When pressable the card inherits Card's `role='button'` + `tabIndex=0` keyboard semantics. The skeleton container uses `role='status'` + `aria-busy='true'` and announces "Loading" (from `@timeui/core` i18n).
</Callout>
