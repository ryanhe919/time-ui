# 统计卡片 StatCard

KPI 场景专用卡片。固定 label + value 布局、delta pill 带 arrow tick 动画、可选 icon 容器 / description / trend 插槽 / 骨架态。其他治理参数（variant / color / size / radius / accentBar / pressable / href）都直接透传给内部 `Card`。

<Callout variant="info" title="Card 还是 StatCard？">
  - 需要展示单条 KPI（数字 + 变化率 + 趋势图）用 **StatCard**，无需自己组装排版。
  - 展示结构化内容、表单、表格或任意组合 — 用 **Card**。
</Callout>

## 基础用法

`label` + `value` 是最小集。label 小写 uppercase + tracking（CJK 文字会自动关掉 uppercase、换成更易读的字号），value 使用 tabular-nums 与 slashed-zero。

<LiveDemo code={`<StatCard label="活跃用户" value="12,480" />`}>
  <div style={{ width: 'min(280px, 100%)' }}>
    <StatCard label="活跃用户" value="12,480" />
  </div>
</LiveDemo>

## Delta 三态

`delta.direction` 为 `'up' | 'down' | 'flat'`；polarity 默认 `'auto'`——up 即正向（绿）、down 即负向（红）、flat 中性灰。业务语义颠倒时（例如 churn 越低越好）可以手动传 `polarity='negative'` 锁定颜色。下方按钮切换快照会让 arrow tick 动画重播。

<LiveDemo code={`<StatCard label="月度经常性收入" value="$128,402" delta={{ value: '+12.4%', direction: 'up' }} />
<StatCard label="客户流失率" value="2.1%" delta={{ value: '-0.4pp', direction: 'down' }} />
<StatCard label="NPS" value="54" delta={{ value: '0', direction: 'flat' }} />`}>
  <StatCardDeltaDemo />
</LiveDemo>

## 带 Icon

`icon` 是任意 ReactNode，会被放进一个尺寸随 size 变化的容器里；`iconPlacement` 在 `'start'`（默认）与 `'end'` 之间切换。icon 容器使用 `aria-hidden`，不会进入可访问性树。

<LiveDemo code={`<StatCard
  label="订单"
  value="3,248"

  iconPlacement="start"

## Emphasis 三档

`emphasis` 决定 value 字号 / 字重 / 行高：`subtle`（20px） / `default`（28px） / `strong`（36px）。同一行的 delta / description 会对齐基线。

## 可按 / 链接化

StatCard 透传 `isPressable` / `isHoverable` / `href` 等，整卡可跳转或响应 `onPress`——常见于仪表板卡片点击钻取详情。`href` 会把根节点渲染成 `<a>`。

<LiveDemo code={`<StatCard
  isHoverable
  href="#revenue"
  aria-label="跳转到营收详情"
  label="营收"
  value="$1.2M"
  description="点击查看详情"
  delta={{ value: '+14%', direction: 'up' }}
  accentBar="start"
  color="primary"
/>
<StatCard
  isPressable
  isHoverable
  onPress={() => console.log('pressed')}
  label="订单量"
  value="3,248"
  description="按下触发 onPress"
  delta={{ value: '-2.1%', direction: 'down' }}
  variant="elevated"
/>`}>
  <StatCardPressableDemo />
</LiveDemo>

## 注意事项

<Callout variant="info" title="delta aria-label 的降级">
  当 `delta.value` 是字符串时，屏幕阅读器会念完整句（"上升 12.4%"）。但若你把 `delta.value` 传成 ReactNode（比如一个带 span 的富文本），组件拿不到纯文本——此时 aria-label 只会念方向词（"上升" / "下降" / "持平"）。需要完整播报时请手动传 `sr={{ deltaLabel: '上升 12.4 百分点' }}` 显式兜底。
</Callout>

<Callout variant="info" title="label 自动切 CJK 模式">
  label 是字符串且包含 CJK 时，组件会自动关掉 uppercase 与放大字号，避免中文在 uppercase + tracking 下变形。上面的演示里 "活跃用户" / "订单" 等就是这个效果。想保留 uppercase 效果请在 label 中使用英文（见 ColorVariants 那组）。
</Callout>

<Callout variant="info" title="整卡 pressable 时避免嵌入另一个焦点目标">
  StatCard 内通常只有 value / delta，本身不包可聚焦元素。但若你在 `description` 或 `trend` 里放 `<Button>` / `<a>`，会与外层的 pressable 叠成两个焦点目标——把次级入口做成次级 Card 或菜单更稳。
</Callout>

  delta pill 带 `role='status'` 与 `aria-label`（按 i18n 拼出"上升 / 下降 / 持平 `{value}`"，或使用 `sr.deltaLabel` 覆盖）；整卡 pressable 时沿用 Card 的 `role='button'` / `tabIndex=0` 键盘语义。骨架态 `role='status'` + `aria-busy='true'`，读屏会念 "加载中"（来自 `@timeui/core` 的 i18n 字典）。
</Callout>
