# Badge

A small label that decorates the corner of another element: unread counts, status dots, "has updates" markers. Two variants (`standard` numeric / `dot`), four placements, five colours, optional pulse animation, and a hide flag.

<Callout variant="info" title="Badge vs. Tag">
  - **Badge** — attaches to another element (icon corner, button, avatar) and conveys a count or status.
  - **Tag** — a stand-alone label, usually with text content, often closable / pressable.
</Callout>

## Basic usage

Pass the decorated element as `children`; the Badge positions absolutely into the corner. Numeric `content` is clamped by `max` (default 99) and rendered as `99+`.

<LiveDemo code={`<Badge content={5} color="danger">
  <Avatar name="Ada" />
</Badge>
<Badge content={120} max={99} color="primary">
  <Avatar name="Bob" />
</Badge>`}>
  <Flex gap={24} align="center">
    <Badge content={5} color="danger">
      <Avatar name="Ada" />
    </Badge>
    <Badge content={120} max={99} color="primary">
      <Avatar name="Bob" />
    </Badge>
  </Flex>
</LiveDemo>

## Dot variant

`variant="dot"` renders a small textless dot — perfect for "unread / online / has updates" markers.

<LiveDemo code={`<Badge variant="dot" color="success">
  <Avatar name="Ada" />
</Badge>
<Badge variant="dot" color="danger" isPulse>
  <Avatar name="Bob" />
</Badge>`}>
  <Flex gap={24} align="center">
    <Badge variant="dot" color="success">
      <Avatar name="Ada" />
    </Badge>
    <Badge variant="dot" color="danger" isPulse>
      <Avatar name="Bob" />
    </Badge>
  </Flex>
</LiveDemo>

## Placement

Four corners — `top-right` (default) / `top-left` / `bottom-right` / `bottom-left`.

<LiveDemo code={`<Badge content="N" placement="top-right">    <Avatar /></Badge>
<Badge content="N" placement="top-left">     <Avatar /></Badge>
<Badge content="N" placement="bottom-right"> <Avatar /></Badge>
<Badge content="N" placement="bottom-left">  <Avatar /></Badge>`}>
  <Flex gap={24} align="center">
    <Badge content="N" color="primary" placement="top-right"><Avatar /></Badge>
    <Badge content="N" color="primary" placement="top-left"><Avatar /></Badge>
    <Badge content="N" color="primary" placement="bottom-right"><Avatar /></Badge>
    <Badge content="N" color="primary" placement="bottom-left"><Avatar /></Badge>
  </Flex>
</LiveDemo>

## Hiding and zero

- `isInvisible` — keeps the layout but hides the badge (handy for "fade out after read" animations).
- `showZero` (default `false`) — render even when the value is `0`.

```tsx
<Badge content={count} isInvisible={count === 0}>
  <BellIcon />
</Badge>
```

## Single character + outline

- `isOneCharacter` — pin the badge to a perfect circle, ideal for one-character / one-digit content.
- `showOutline` (default `true`) — adds a ring matching the background colour so the badge lifts off complex surfaces.

<Callout variant="info" title="Accessibility">
  Badge is decorative: the standard variant uses `aria-label` to announce the value; the dot variant requires an explicit `aria-label` describing its meaning (e.g. "unread"). When `isInvisible`, the DOM node is kept with `aria-hidden="true"`.
</Callout>
