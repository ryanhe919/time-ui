# AI Chat Overview

TimeUI's `Chat` family is for building production-grade LLM chat surfaces: message stream, tool calls, knowledge citations, streaming caret, and an extensible composer — all unified through the design tokens. The components are protocol-agnostic — pipe an OpenAI / Anthropic / your-own SSE stream into an `AsyncIterable<string>` and feed it to `useChatStream`.

## Component family

| Component                             | Role                                                                                                                                                               |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `ChatMessageList`                     | Vertical container, optional `maxHeight` scroll with auto-stick-to-bottom, `role="log" aria-live="polite"`.                                                        |
| `ChatMessage`                         | Single message — 5 built-in roles (`user` / `assistant` / `system` / `tool` / `knowledge`), optional avatar, name, timestamp, streaming caret, attachments slot.   |
| `ChatAvatar`                          | Round avatar — image / text initials / arbitrary node, role-tinted background.                                                                                     |
| `ChatTypingIndicator`                 | Three-dot bouncing indicator (degrades to pulse under `prefers-reduced-motion`).                                                                                   |
| `ChatToolCall`                        | Collapsible tool-call card, 4 statuses (pending / running / success / error), auto JSON-serialises args / result, custom `renderArguments` / `renderResult` slots. |
| `ChatKnowledgeRefs`                   | Citation chips — clickable link / button / static span, source-typed initial badge.                                                                                |
| `ChatComposer`                        | Auto-grow textarea, Enter submits / Shift+Enter newline, IME-composition safe, four extension slots (start / end / top / bottom).                                  |
| `ChatActionButton` / `ChatSendButton` | Composer toolbar icon button + primary send button.                                                                                                                |
| `useChatStream`                       | Streaming hook: consume an `AsyncIterable<string>`, accumulate text, expose `text` / `isStreaming` / `error` / `start` / `cancel` / `reset`.                       |

## Streaming

The components carry no fetch logic and bind to no SSE protocol. `useChatStream` accumulates any `AsyncIterable<string>` into `text`; pair it with `<ChatMessage isStreaming>` to show the blinking caret. The demo below uses `setTimeout` slicing to simulate a stream:

<LiveDemo previewSource="children" code={`import { useChatStream, ChatMessage, ChatMessageList, Button } from '@timeui/react';

async function\* fakeStream(text: string) {
for (let i = 0; i < text.length; i += 6) {
await new Promise((r) => setTimeout(r, 40));
yield text.slice(i, i + 6);
}
}

export function StreamDemo() {
  const stream = useChatStream();
  return (
    <>
      <Button onClick={() => stream.start(fakeStream('Hello world…'))}>Start</Button>
      <Button onClick={stream.cancel}>Cancel</Button>
      <ChatMessageList>
        {stream.text || stream.isStreaming ? (
          <ChatMessage role="assistant" isStreaming={stream.isStreaming}>
            {stream.text}
          </ChatMessage>
        ) : null}
      </ChatMessageList>
    </>
  );
}`}>
  <ChatStreamingDemo />
</LiveDemo>

## Visual rules per role

- **`user`** — right aligned, `primary[100]` bubble, avatar on the right
- **`assistant`** — left aligned, `bg.surface` bubble with hairline border, avatar on the left
- **`system`** — centered, no bubble, `default[100]` pill, no avatar
- **`tool`** — left aligned, no bubble (header only), pass `<ChatToolCall>` via `attachments`
- **`knowledge`** — left aligned, no bubble, pass `<ChatKnowledgeRefs>` via `attachments`

Bubble corners use `bubbleRadius` (18px) on three sides; the corner closest to the avatar shrinks to `bubbleRadiusSmall` (6px) for an iMessage-style "tail".

<Callout variant="info" title="Accessibility">
  `ChatMessageList` defaults to `role="log" aria-live="polite" aria-relevant="additions"` so screen
  readers announce new messages. `ChatMessage` uses `role="article"` to make each message a discrete
  unit. `ChatTypingIndicator` uses `role="status"` + `aria-live="polite"`. All animations downgrade
  gracefully under `prefers-reduced-motion: reduce`.
</Callout>

## Recommended combinations

- Main chat surface: `ChatMessageList` + `ChatMessage` + `ChatComposer`
- Agent process visibility: `ChatMessage role="tool"` + `ChatToolCall`
- RAG / retrieval UX: `ChatMessage role="knowledge"` + `ChatKnowledgeRefs`
- Streaming output: `useChatStream` + `ChatMessage isStreaming`
- Voice or multimodal input: `ChatComposer` + `ChatActionButton` + `ChatVoiceWave`
