## useChatStream

```ts
const { text, isStreaming, error, start, cancel, reset } = useChatStream({
  onStart?: () => void;
  onUpdate?: (text: string) => void;
  onComplete?: (finalText: string) => void;
  onError?: (error: unknown) => void;
});
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `text` | `string` | 自上次 reset 起累加的文本。 |
| `isStreaming` | `boolean` | 介于 start 与 complete / error / cancel 之间为 true。 |
| `error` | `unknown \| null` | 最近一次错误，下次 start 时清零。 |
| `start(chunks)` | `(chunks: AsyncIterable<string>) => Promise<string>` | 开始消费迭代器，每次 yield 的字符串**追加**到 `text`，最终返回累加结果。 |
| `cancel()` | `() => void` | 中止当前流（abort）；不触发 onError。 |
| `reset()` | `() => void` | 仅清空 `text`，不影响进行中的流。 |
