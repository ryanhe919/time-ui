## useChatStream

```ts
const { text, isStreaming, error, start, cancel, reset } = useChatStream({
  onStart?: () => void;
  onUpdate?: (text: string) => void;
  onComplete?: (finalText: string) => void;
  onError?: (error: unknown) => void;
});
```

| Field | Type | Description |
| --- | --- | --- |
| `text` | `string` | Accumulated text since last reset. |
| `isStreaming` | `boolean` | True between start and complete / error / cancel. |
| `error` | `unknown \| null` | Last error, cleared on next start. |
| `start(chunks)` | `(chunks: AsyncIterable<string>) => Promise<string>` | Consume the iterable; each yielded string is **appended** to `text`. Resolves with the final accumulated text. |
| `cancel()` | `() => void` | Abort the current stream; does not fire onError. |
| `reset()` | `() => void` | Clear `text` only; does not affect a running stream. |
