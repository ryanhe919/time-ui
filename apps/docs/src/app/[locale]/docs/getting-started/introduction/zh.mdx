# 介绍

TimeUI 是一个**灵活、可访问、可主题化**的 React 组件库，既让开发节奏更快，也不牺牲定制能力。

## 为什么选择 TimeUI？

- **默认可访问** —— 符合 WAI-ARIA，键盘可达，屏幕阅读器友好。
- **主题化** —— 基于类型化设计 token，一等公民的浅色/深色主题支持。
- **TypeScript 优先** —— 精确、完整的类型定义随包分发。
- **按需引入** —— 支持 Tree-shaking，只打包你用到的部分。
- **国际化** —— 内置中文（默认）与英文 messages。
- **AI 友好** —— 独立的 `@timeui/mcp` 包把所有组件文档暴露为 MCP 工具，Claude Code / Cursor 可直接查询；`@timeui/react/chat-markdown` 为 AI 对话提供流式 markdown 渲染。
