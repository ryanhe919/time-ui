# Introduction

TimeUI is a **flexible, accessible, and themeable** React component library
designed to accelerate your development workflow without sacrificing
customization.

## Why TimeUI?

- **Accessible by default** — WAI-ARIA compliant, keyboard navigable, screen-reader friendly.
- **Themeable** — Typed design tokens with first-class light/dark themes.
- **TypeScript-first** — Precise, fully-typed APIs shipped alongside.
- **Tree-shakeable** — Import only what you use.
- **Internationalized** — Chinese (default) and English messages built in.
- **AI-ready** — the companion `@timeui/mcp` package exposes every component's documentation as callable MCP tools for Claude Code / Cursor; `@timeui/react/chat-markdown` streams assistant output with proper markdown rendering.
